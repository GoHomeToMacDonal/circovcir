## 关键事实

**r₁₀ = 1 + 2cos(2π/9) = 2.5320888862…**，即本引理的 ∂C₁₀ 半径 = n=10 覆盖半径 R₁₀ 本身。（有时被挂在「r₁₀」上的 1.7988 其实是 n=6 记录值 r₆，不是本引理半径。）由 [FT] 印刷常数 `7 arcsin(1/r₁₀)=2.841948021` 反解得同一值。

## h(ϑ) 第一性原理表达式

两个对称单位圆共覆 ∂C₁₀ 一段测度 ϑ 的弧（对称位各覆 ϑ/2）；o 到二圆边界内交点 p 的距离 h(ϑ)。单位圆过共享内端点 A=(r₁₀,0) 与远端点 B=r₁₀(cos(ϑ/2),sin(ϑ/2))，圆心 c 到二者距 1、取内侧；镜像对在 x 轴交于 p=(cₓ−√(1−c_y²),0)。闭式（分支经 [FT] 印刷数验证）：

```
cx = w cos²(ϑ/4) − cos(ϑ/4)·√(1 − w²sin²(ϑ/4))
cy = w sin(ϑ/4)cos(ϑ/4) − sin(ϑ/4)·√(1 − w²sin²(ϑ/4))     (w = r₁₀)
h(ϑ) = cx − √(1 − c_y²)        域 0 ≤ ϑ ≤ 4 arcsin(1/r₁₀)
```
