# n=11「1 内圆 + 10 外圆」类在 R=2.631 的见证点暴力搜索

- 日期：2026-10-11
- 问题 / 假设：类 C10(R) = {11 个单位圆，其中 c₁..c₁₀ 满足 |cᵢ| ≥ R−1（都够到边界圆），c₀ 任意（因 R−1>1，必由 c₀ 覆盖原点）}。假设：C10(2.631) 中**不存在**覆盖 D(0,2.631) 的构型。注意 Melissen 记录是 b=9（两内圆），不在此类中。
- 方法：入口 `run.py`。有限见证集 W（nb 个等距边界点 + ni 个向日葵内部点）；t_W(c)=max_{w∈W} minᵢ|w−cᵢ|。若 C10 中有覆盖，则对**任何** W 都有 min t_W ≤ 1，所以 W 越大松弛越紧。每个起点：log-sum-exp 光滑化 + 环约束罚函数（L-BFGS 退火）→ W 上固定指派 SLP（HiGHS LP，信赖域）→ 全盘精确候选点 active-set 极小极大 polish（带环约束 SLSQP，`circovcir.optimize` 的候选点生成器）。种子：一半随机环带布局，一半扰动正则 10 环（σ∈[0.02,0.4]）；种子固定 = 起点编号。
- 复现：

```bash
uv run python experiments/2026-10-11-n11-b10-witness/run.py --nb 48 --ni 120 --starts 120
uv run python experiments/2026-10-11-n11-b10-witness/run.py --nb 2400 --ni 80000 --starts 64
```

（32 核机器；每次运行 ≤ 2.5 min；`--time-limit` 默认 290 s 后停止收集结果。）

- min t_W 取「见证阶段解」与「精确 polish 解在 W 上的值」两者的最小。
- 全盘精确 polish 所有起点都收敛到 ρ=1.004952575599 > 1；最优解即**正则 10 环 + 中心圆**（|c₀|<1e-8，外圆半径 = 2cos(π/10)·ρ 至 3e-9，角距偏差 <1e-6°），R/ρ = 1+2cos(π/5) = 2.618033988750 至 12 位。c/ρ ∈ C10(R/ρ) 且覆盖 D(0,R/ρ)，所以这只说明「找到的最好 C10 覆盖半径是 2.618…」。
- |W| = 82400 时 64 个起点中无一能覆盖 W（min t_W = 1.00126）。

## 结论与边界

- **L1 数值证据**：在 R=2.631，本方法在 C10 类中**未找到**覆盖构型；该类找到的最佳半径是正则环的 2.6180，比 2.631 小 0.013。与 `proofs/11` 的 W10 轮型条件排除一致。
- 这**不是**排除证明：多起点局部搜索不穷尽，「W 上无解」只表示「搜索没找到覆盖 W 的构型」。升 L3 需要对固定 W（如本表最后一行的 82400 点，或更少的自适应点）证明**全局** min_{C10} t_W > 1，例如穷尽分支定界（`src/circovcir/branchbound.py` / `exclusion.py` 的思路）；局部搜索给不了全局下界。
- 观察：ρ 的极小点间隙只有 0.00495，均匀见证点要 ~8×10⁴ 个才能把松弛推过 1；更小的 W 都可被覆盖，不能用于排除。
