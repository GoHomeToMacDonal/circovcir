# n=11 / b=9：旋转漏检、自适应精确见证与两圆残集

- 日期：2026-10-10。
- 目标：对全部九边界圆构型建立锋利上界；**本轮未完成**。
- 可检验假设：固定点会漏掉旋转后的微小孔洞；用参数盒统一漏点 + 精确两圆冲突可以严格排除外九圆盒而无需枚举两内圆。
- 方法：Python 浮点只提出见证；有理数检查、Helly 冲突二着色、独立证明树回放决定排除；Wolfram 区间证书给全局较粗上界的数值门。
- 单入口：`uv run python experiments/2026-10-10-n11-b9-witness/run.py`。
- 全部确定性，无随机数；回归测试固定种子 20261010/3。
- Wolfram 路径可用 `WOLFRAMSCRIPT` 指定，入口检查退出码和成功标记。
