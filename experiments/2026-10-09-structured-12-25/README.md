# 2026-10-09 n=12..25 — 分层种子结构化搜索，复现 Friedman 记录

- 日期：2026-10-09
- 问题 / 假设：记录构型（Melissen 1997 / Tan 2018）的层结构是“b 个外层圆与 O 相交（相邻两圆的外交点恰在 ∂O 上）+ 内层若干环”，内部由大量三圆共点钉死。按页面图片与层数提示（12:9, 13:10, 14:10, 15:11, 16–19:12, 20:13）播种，基线优化器应能落入记录盆地；再在固定紧集上解 KKT 方程组得高精度 R。
- 方法：
  1. `search.py N [starts] [seed]`：同心环种子（外→内层数 spec，随机环半径/相位/抖动；`specs_for` 对 n≥21 枚举 b=12..17 与内层分法），光滑退火（起始温度高，保层结构）+ 精确候选集 active-set `polish`；30 进程，固定种子 `1000003·n+s`。BLAS 线程强制 1（否则 30×32 线程把负载顶到 ~400）。
  2. `prep.py N 1e-8`：取最优 float 构型，抽活跃候选点（T=三圆共点，B=两圆交点在 ∂O 上）。
  3. `kkt.wls in out 50`：**多项式** KKT 形式（每个活跃点带自己的点变量，所有方程二次），max R 的驻点条件 + 旋转规范，Gauss–Newton（LeastSquares 步）wq=2wp+20；再用 `MaxCoveredRadius`（wp=50）独立复核 R（防漏约束）。
  4. `save.py N` → `data/configs/NN/20261009-structured-kkt.json`，`uv run circovcir verify … --wolfram` 通过后升 `verified-numeric`。
  5. n=19、25 的 KKT 退化（全部候选点都紧、秩亏）→ 由 float 坐标直接识别闭式：`n19_exact.wls`（六角格 spacing √3 的 19 点）、`n25_exact.wls`（D8：1 + 8@2cos(π/8) + 8@(2+√2)·e^{i(π/8+kπ/4)} + 8@4cos(π/8)）。
- 复现：`uv run python experiments/2026-10-09-structured-12-25/search.py N 30`（n≤20，~1–6 min/个）或 `… N 12`（n≥21，~10–35 min/个）；然后 `prep.py N`、`wolframscript -file kkt.wls out/nNN-float.json out/nNN-kkt.json 50 </dev/null`、`save.py N`。
