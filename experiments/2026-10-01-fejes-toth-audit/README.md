# Fejes Tóth (2005) 第 2 节逐格不等式审计

- 日期：2026-10-01
- 问题：要去掉 `proofs/01-ring-symmetry.md` 的结构假设 H_k，打算以 G. Fejes Tóth, MSRI Publ. 52 (2005) 361–376 的证明为骨架。先逐条核对它用到的单格不等式。
- 方法：`run.py`（seed 20261001）。设 o_i=(s,0)，R−1 ≤ s ≤ √(R²−1)（这是论文的根轴同侧约定）。q, q′ 在 |x|=R 上，且 |o_i q|, |o_i q′| ≤ 1。先做 2e6 次随机采样，再从 1500 个起点做 SLSQP 局部最大化。
- 复现：`uv run python experiments/2026-10-01-fejes-toth-audit/run.py`，输出见 `results.txt`。

## 结果（L1）

| 不等式 | n=8 | n=9 | n=10 | 结论 |
|---|---|---|---|---|
| G1：θ ≤ f(α)，α < π/3 | +0.084 | +0.087 | +0.088 | **论文原式在小 α 时不成立** |
| G1：θ ≤ f(α)，α ≥ π/3 | −3e−4 | −4e−4 | −3e−5 | 成立（|o_i q|=1 时取等） |
| G2：area(R_i) ≤ F(α) | ≈0⁻ | ≈0⁻ | ≈0⁻ | 成立（取等于 |o_i q|=|o_i q′|=1） |
| G1T：θ ≤ T(α)，T 为 f 在 ᾱ=6π/(n−1) 处的切线 | 0（取等于正则环） | 0 | 0 | 成立，可作补丁 |

**缺口的成因**：论文默认弦长 |qq′| = 2sin(α/2)，这只在 |o_i q| = |o_i q′| = 1 时成立。一般情况下，由 |qq′|² = a² + b² − 2ab cos α（a, b ≤ 1）只能得到 |qq′| ≤ max(2sin(α/2), 1)。当 α < π/3 时，后者可以是 1，大于 2sin(α/2)。

**补丁**：论文的 (3) 式只需要 Σθ_i = 2π ≤ Σ T(α_i)，由此即得 Σα_i ≥ (n−1)ᾱ，后续论证不变。剩下的工作是对 α < π/3 的区域把 G1T 证严格：
- 粗界 θ ≤ f(π/3) ≤ T(0) 只对 n=8 够用（余量 +0.153）；n=9 余量 −0.036，n=10 余量 −0.140，都不够；
- 因此需要对 (s, t₁, t₂) 做区间分支定界。SLSQP 给出的余量为 n=8: −0.268，n=9: −0.144，n=10: −0.081（α ≤ π/3 时的最大值都取在 α = π/3、|o_i q| = 1）。
