# b=9 精确直线分割与自适应残集：R<2.725

日期2026-10-11，只处理b9。

## 初始假设（L0）

旧传播器未闭合可能有两种原因：有限点集本来不可两圆覆盖而求解器未找出；或现有点确实可覆盖。实现13 §5a的精确直线分割判据区分它们，并用有限覆盖圆心提出新漏点。

## 复现

```bash
uv run python experiments/2026-10-11-n11-b9-separation/run.py
```

确定性；所有正答案逐点有理距离核验，负答案逐个完整方向室检查Helly冲突。有限覆盖只用来找新点，不约束真实两内圆位置。新点必须全外圈域统一漏出。

## 结果

**L3计算，几何归约待人工复核**：完整排除[2.725,2.73]全部56名次域，接独立重跑18a/17a/16a/15b得全b9 R<2.725。锋利R*界未证明。

- 44/8/4域每中心1/4/8片；最终15–28点/域。
- 1176个统一漏点、12043个精确方向室、1319条冲突边。
- 33域需要新增点，最多3轮。
- 主证书 `results/separated-cover.json` 约1.3MB；日志 `results/separated-cover.log`。
- 九个更低区间有限点集有两圆覆盖，点与圆心存 `results/finite-covered-diagnostics.json`，Py/WL直接核验；不是全目标盘覆盖。

通用代码 `src/circovcir/{two_disk_separation,separated_residual}.py`，文档 `proofs/19-n11-b9-separation.md`，独立证书 `19a-n11-separated-cover.wls`。
