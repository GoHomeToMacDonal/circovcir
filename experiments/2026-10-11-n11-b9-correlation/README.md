# b=9 中心逐个切片：R<2.73

日期：2026-10-11。仅b9，不处理b10。

## 假设与方法

初始L0：直接在全名次多面体上求角度支持比坐标盒更强。实际根域收益小；转为条件角度界：逐个中心将u_j范围分为1/4/8段，每段用原始多面体+片段界的精确LP对偶包住角度。全部片段的扇形并集包住该中心，避免虚假的半径—角度组合。

没有假设中心之间独立，没有把扇形片数当成外圆数。全部算法在 `src/circovcir/{correlated_sectors,sliced_sectors}.py`，残集归属传播复用17。
