# S5：取等 ⟹ 构型全等（n = 8, 9, 10 无条件最优性的最后一关）

- 日期：2026-10-09
- 问题 / 假设：Fejes Tóth n=8,9,10 无条件最优性证明里 `proofs/02` 步骤表的 **S5**（原状「取等 ⟹ 构型全等，待写细节」）。目标命题：当覆盖半径取到 `R_n = 1+2cos(2π/k)`（k=n−1）时，最优构型模旋转唯一 —— 中心圆 D(0,1) 加 k 个在距 O 为 `2cos(π/k)` 处等角分布的单位圆（`RingConfig[k]`）。
- 方法：S5 **不是**零维代数系统（对比 `proofs/07` 的 n=11 局部最优性，那里确实归约为 22×22 KKT 盒用 Krawczyk 封）。S5 的唯一性来自**等号情形的刚性**：严格凹 Jensen（(3)、(6)）与严格单格界（G1T、G2）各自把每个胞腔钉死到正则胞腔，没有残余自由参数。因此**不配 Krawczyk 盒**（会是装饰、无增量）。证书的职责是把「等号 ⟹ 各参数相等 / 接触被迫」所依赖的**严格性事实**做成有限、向外舍入的数：

  | 事实 | 内容 | 作用 | 等级 |
  |---|---|---|---|
  | R1 | f″<0 于 (0,π)（自适应二分区间） | (3) 严格凹 Jensen 取等 ⟺ 所有 αᵢ 相等 | L3 |
  | R2 | F″<0 于 (0,π)（自适应二分区间） | (6) 严格凹 Jensen 取等 ⟺ 所有 αᵢ 相等 | L3 |
  | R3 | g 在 [ᾱ,π] 严格递减（g′(ᾱ)<0 精确 + g″<0 区间） | S4 收尾界取最大仅在 α-mean=ᾱ ⟹ Σαᵢ=kᾱ | L3 |
  | R4 | 单格取等轨迹 = 正则胞腔（RootReduce 精确）：T(ᾱ)=f(ᾱ)、R·sin(π/k)=sin(3π/k)（即 f(ᾱ)=2π/k=θ̄）、ring 在接触面 \|u\|=1 上 α=ᾱ | 每格 αᵢ=ᾱ+接触 ⟹ θᵢ=2π/k，Tᵢ 全等于正则 | L3（精确） |
  | R5 | 等角闭合被迫（精确）：k·θ̄=2π、`RingConfig[k]` 精确紧覆盖 | k 段 2π/k 弧首尾相接铺满 ∂C_n ⟹ 中心等角 @ 2cos(π/k) | L3（精确） |

- 复现：`wolframscript -file experiments/2026-10-09-s5-rigidity/run.wls`（单入口，驱动证书）
  或直接 `wolframscript -file proofs/certificates/05d-s5-equality-rigidity.wls ; echo "EXIT=$?"`

## 结果

证书 `proofs/certificates/05d-s5-equality-rigidity.wls`：**exit 0**，R1&R2&R3&R4&R5 对 n=8,9,10 全 True（全部有限、向外舍入 ≥25 位）。

| n | R | R1 worstUpper(f″) | R2 worstUpper(F″) | R3 g′(ᾱ) | R4 | R5 | 等级 |
|---|---|---|---|---|---|---|---|
| 8 | 2.2469796037… | −3.16e−5 | −9.33e−5 | −0.457271 | True | True | L3 |
| 9 | 2.4142135624… | −3.93e−5 | −1.10e−4 | −0.207107 | True | True | L3 |
| 10 | 2.5320888862… | −2.75e−6 | −1.18e−4 | −0.005572 | True | True | L3 |

R1/R2 的 α→0 第一面板是**区间高估**（f″、F″ 分子趋 0，端点包裹松）而非真实变号：逐点 f″≈−1e−4 严格负，自适应二分（最大深度 1–5）即把高估清零。R4 的三条恒等式是**代数数等式**，`Simplify===0` 判不出（arcsin/arccos 形），改用 `RootReduce`（精确，与 `CirCovCir`sgn` 处理近零同工具）；关键恒等式是 `R·sin(π/k)=sin(3π/k)`（RootReduce=0 精确，⟺ f(ᾱ)=2π/k）。

## 取等 ⟹ 全等 的链（link-by-link，附等级）

```
[hyp]  最优覆盖精确取到 R=R_n                                        （S5 前提）
  → [FT S1/S2] 恰一个圆在 int C_n 内；其余 k 个各占一个边界 Dirichlet 胞腔
                （n=8,9: arcsin 计数；n=10: Melissen 距离引理 cert 05c）  [L3 基于 FT 转引]
  → [S3b 05b] 2π=Σθᵢ ≤ ΣT(αᵢ)；逐格取等 ⟹ 接触 |u|=1 且落在紧轨迹      [L3, exit 0]
  → [S4 05]   面积取等（覆盖取到 R_n ⟹ 胞腔面积和=a(C_n)）⟹ 收尾界紧；
              R3 + α-mean≥ᾱ（由 (3)）⟹ α-mean=ᾱ                        [L3, exit 0]
  → [R1,R2]   严格凹 Jensen (3)&(6) 取等 ⟹ 所有 αᵢ 相等 = ᾱ            [本证书 L3]
  → [R4]      每格 αᵢ=ᾱ、双顶点接触（G2 取等 |oq|=|oq′|=1）、θᵢ=2π/k
              ⟹ 每个三角形 Tᵢ 全等于正则 Tᵢ*（eq.(1): Σδᵢ=Σεᵢ=2π）     [本证书 L3]
  → [R5]      k 格 × 2π/k = 2π 铺满 ∂C_n ⟹ 中心等角 @ 2cos(π/k)
              = RingConfig[k] 模旋转。                                   [本证书 L3]
= RingConfig[k] 模旋转。  QED S5
```

**封闭 vs 开放（诚实红线）**：
- **封闭（L3）**：R1–R5 五条严格性事实本身（本证书 exit 0，有限向外舍入 / RootReduce 精确）。
- **S5 作为定理** = 把 R1–R5 与它所依赖的三个计算证书（S3b=05b、S4=05、n=10 的 Melissen=05c）**组合**成的几何演绎。它**不**引入新的自由代数系统，故无 Krawczyk 盒。
- **等级上限诚实封顶**：S5 定理取其最弱依赖的等级：
  - n=8,9：**L4-条件**（仍待人工复核 [FT] 面积论证本身，与 01/05 的既有条件状态一致）；
  - n=10：额外搭在 **未取得的 Melissen 原文**（pp.108–111）上（05c 本身是「基于 [FT] 转述」的 L3），故 n=10 的无条件性比 n=8,9 多一道待核实依赖。
- 没有任何链环被含糊带过：每一环都标了来源证书与等级；R1/R2 的近零高估、R4 的 Simplify 失败都已定位为**工具问题**（区间高估 / 代数数判等），用自适应二分与 RootReduce 修掉，而非放宽量词。
