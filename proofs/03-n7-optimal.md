## 定理

$$R_3 = \tfrac{2}{\sqrt3},\qquad R_4 = \sqrt2,\qquad R_7 = 2.$$

## 0. 公共工具：单圆弧上界

记 Γ_R = {|x| = R}，一个圆心距 O 为 d 的单位圆盘与 Γ_R 相交得一段弧，圆心角

$$\omega(R, d) = 2\arccos\frac{R^2 + d^2 - 1}{2Rd} \le 2\arcsin\frac1R =: A(R),$$

上确界在 d = √(R²−1) 取到（引理 1 + 推论 (b)，见 `01`；证书 E_max 复核极值点与极值）。A(R) = 2 arcsin(1/R) 在 R > 1 上**严格递减**（A′(R) = −2/(R√(R²−1)) < 0，证书 E_dec）。

**三个精确踩点**（证书 E_hit）：

| n | R_n | A(R_n) | 等于 |
|---|---|---|---|
| 3 | 2/√3 | 2π/3 | **2π/n** |
| 4 | √2 | π/2 | **2π/n** |
| 7 | 2 | π/3 | **2π/(n−1)** |

n=3,4 踩的是 2π/**n**，n=7 踩的是 2π/**(n−1)**——差别就是 n=7 要额外扣一个圆给中心（见 §3）。

## 1. n = 3, 4：边界弧计数（最简形）

**可达性（R = R_n 可被覆盖）：L3。** `known.json` 的构型（n=3：等边三角形圆心在距 O 为 1/√3 处；n=4：正方形圆心在距 O 为 1 处）满足 `ExactCoverQ[LoadConfig, R_n]` = True、`+10⁻³⁰` = False（证书 E_cover3、E_cover4）。故 R_n ≥ R_n^*。

**上界（R > R_n 不可覆盖）：无条件。** 设 R > R_n，反设 n 个单位圆盘覆盖 D(0,R)。Γ_R ⊂ D(0,R) 被这 n 个圆盘覆盖，每个贡献 Γ_R 上一段弧，弧长 ≤ A(R)。因 A 严格递减且 A(R_n) = 2π/n：
$$R > R_n \implies A(R) < A(R_n) = \frac{2\pi}{n}.$$
于是 n 段弧总长 < n·(2π/n) = 2π，**盖不满 Γ_R**，矛盾。所以 R_n ≤ R_n^*。∎

合并：**R₃ = 2/√3，R₄ = √2**。注意这里**没用**中心圆步骤——边界本身已不可覆盖。

## 2. n = 7：边界计数 + 中心扣减

n=7 的 A(2) = π/3 = 2π/**6** ≠ 2π/7，所以 §1 的直接计数给不出 7。需要多一步。

**可达性 R₇ ≥ 2：L3。** 正则环 `RingConfig[6]`（O + 6 个圆心在距 O 为 √3 处等角分布），`RingRadius[6] = 1 + 2cos(π/3) = 2`，`ExactCoverQ[RingConfig[6], 2]` = True、`+10⁻³⁰` = False（证书 E_cover7）。

**上界 R₇ ≤ 2：无条件。** 设 R > 2，反设 7 个圆盘覆盖 D(0,R)。
- **第一步.** R > 2 ⟹ A(R) < A(2) = π/3。设有 t 个圆盘触及 Γ_R（|d_i − R| < 1）。覆盖 Γ_R 要求 2π ≤ Σ ω(R,d_i) < t·π/3 ⟹ t > 6 ⟹ **t ≥ 7**。
- **第二步.** 触及 Γ_R 的圆盘有 d_i > R − 1 > 1，其最近 O 的点距 O 为 d_i − 1 > 0，**覆盖不了 O**。（等价：覆盖 O 需 d ≤ 1，最远点距 O ≤ 2 < R，够不到 Γ_R。）证书 E_step2。
- **第三步.** O 必被某圆盘覆盖，该圆盘不在那 t 个之列 ⟹ 总数 ≥ t + 1 ≥ 8 > 7，矛盾。∎

合并：**R₇ = 2**。

## 3. 为什么 n=3,4 比 n=7 还简单，而 n≥8 两法皆失效

- n=3,4：A(R_n) 恰为 2π/**n**，边界弧计数直接给矛盾，无需管内部/中心。几何上最优构型本来就**没有中心圆**（n 个圆心在一圈上），所以边界计数就是全部。
- n=7：A(2) 恰为 2π/**6**，比 7 少一个。缺的这一个由"覆盖 O 的圆盘够不到 R > 2 的边界"补上（第二步），正因为 R₇ = 2 把临界距离卡在 d+1 = 2 上。最优构型是 O + 正则 6 环，中心圆是必需的。
- n≥8：R_8^* = 1 + 2cos(2π/7) ≈ 2.247，A(R_8^*) ≈ 0.927 > 2π/8 = 0.785，单圆弧长仍够大，第一步的硬计数失效；同时 R < 2 之外的几何也让"中心扣减"不再干净。所以必须退回 `01` 的切线细算 / `02` 的面积论证。

**适用边界总结**：弧计数法恰好覆盖 A(R_n) ∈ {2π/n, 2π/(n−1)} 踩整数的情形，即 n = 3, 4, 7（另有 n=1,2 平凡）。这是本仓库用初等方法能无条件拿下的全部。
