# n=11：Melissen 构型的 L3 覆盖证书

> 结论（L3）：**11 个单位圆能覆盖半径 R = 2.63164999999999957923… 的圆盘，且 R > 2.631（Friedman 页面印刷的记录下界）**，由精确代数算术证明，无浮点介入。
> 证书脚本：`proofs/certificates/06-n11-interval.wls`（可复跑，exit 0）。构型：`data/configs/11/20261002-melissen-exact.json`（status `verified-exact`）。

## 1. 构型

竖直镜像对称（x → −x），11 个单位圆心：3 个在对称轴上（c0 内下、c8 内上、c9 顶），4 对镜像外圆。
来源与高精度构造见 `experiments/2026-10-02-n11-melissen/`（基线搜索 → 旋转轴竖直 → 28 条紧接触方程 `FindRoot` 解、2 内部自由度用 max‑R 定点，R=2.6316907726198078）。

## 2. 为什么用"缩放证书"而非直接 `ExactCoverQ`

这是**紧**覆盖：在约 23 个紧点处 ρ 恰等于 1。把 40 位的高精度圆心四舍五入成有理数（分母 10¹⁵）后，内部的一个紧点（三圆 c0,p4,p4′ 的外心，在 (0,−1.3932)）会被推到距最近圆心 1.0000000000000003 处——一个 ~3×10⁻¹³ 的**内部**空洞，且与 R 无关（降低 R 关不掉它）。所以不能直接对有理圆心取记录 R 跑 `ExactCoverQ`。

`docs/methods.md` 指明的正确做法是**缩放证书**：设 ρ = ρ(c,R) 为覆盖半径，则半径‑1 的圆放在 **c/ρ** 处精确覆盖 **D(0, R/ρ)**。空洞被 1/ρ 的缩放吸收，不再需要圆心恰好满足紧接触。

## 3. 精确算术

- 有理圆心 cs（分母 10¹⁵）、有理 R = 52633/20000 = 2.63165。
- 有限候选集定理（`docs/methods.md`）：ρ(cs,R) 在 260 个候选点（三圆外心 / 中垂线∩边界 / 对径点）处取到；有理圆心 ⇒ 这些点都是**代数数**。
- `rho2 = RootReduce[Max_q Min_i |x_q − c_i|²]`：对代数数取精确最大/最小与 `RootReduce`，得精确 ρ² = 1.00000000000000031977…。
- `Rcert = RootReduce[R / Sqrt[rho2]]` = 2.63164999999999957923…。
- 关键不等式用**精确符号判定**：
  - `RootReduce[Rcert − 2631/1000] > 0` ⟹ **True**（R_certified > 2.631）；
  - `RootReduce[Rcert − 26316/10000] > 0` ⟹ **True**（更强：> 2.6316）。

全程只有代数数与精确有理数，无浮点比较。

## 4. 证书内容与可复现性

`proofs/certificates/06-n11-interval.wls` 内嵌精确有理圆心与 R，重算 ρ²、R_certified 与两个精确不等式，通过则 `Exit[0]`。实测 exit 0。

## 5. 这证明了什么、没证明什么

- **证明（L3）**：存在 11 个单位圆覆盖 D(0, R) 且 R > 2.631 ⟹ 复现并严格确立了 Melissen 记录的**下界**。
- **未证明**：最优性（n=11 仍是开放问题，非"proved optimal"）。上一轮已查明该紧接触构型**非刚性（2 自由度）**，且 R 与坐标是**高次代数数、无实用闭式**（`FindIntegerNullVector` 到 deg≤24 无低高度匹配；`GroebnerBasis` 消元超时）——详见 `research/LOG.md` 2026‑10‑02。
