## A. 公共工具

### A.1 有限候选集定理（`ExactCoverQ` 的基础）

**定理.** 设 c₁,…,c_n 是平面上的点，φ(x) = minᵢ |x − cᵢ|，K = D(0,R)。那么 φ 在 K 上的最大值，在下面这个有限集合 𝒞 的某一点取到：
(T) K 内任意三点 cᵢ, cⱼ, c_k 的外心；(B) 中垂线 {|x−cᵢ| = |x−cⱼ|} 与圆周 |x| = R 的交点；(A) 对径点 −R·cᵢ/|cᵢ|（cᵢ ≠ 0），另加点 (R, 0)。

**证明【人工】.** 设 x* 是 φ 在 K 上的最大点，I 是到 x* 距离最近的那些圆心的下标集合。
- 若 x* ∈ int K 且 |I| = 1：沿远离该圆心的方向移动，φ 增大，矛盾。若 |I| = 2：沿中垂线、朝远离两圆心中点的方向移动（x* 恰为中点时两个方向都行），两个距离同时增大，矛盾。所以 |I| ≥ 3，x* 是其中三点的外心，属于 (T)。
- 若 x* ∈ bd K 且 |I| ≥ 2：x* 落在某条中垂线上，属于 (B)。若 |I| = 1：在 x* 附近 φ = |x − cᵢ|，限制在圆周上它取局部极大，所以 x* 与 cᵢ 反向共线，即 x* = −R·cᵢ/|cᵢ|。cᵢ = 0 时 φ 在这段弧上是常数，弧端点属于 (B)；若整个圆周都属于同一个胞腔，由 (R,0) 兜底。∎

于是「圆心 c 处的 n 个单位圆覆盖 D(0,R)」⟺ ∀x ∈ 𝒞：φ(x) ≤ 1。输入是代数数时，𝒞 中的点也是代数数。`ExactCoverQ` 对每个比较先做 40 位认证数值：若 |1 − |x−cᵢ|²| > 10⁻³⁰ 就直接定号，否则 `RootReduce` 后精确定号（`wl/CirCovCir.wl`，说明见 `docs/methods.md`）。
**【人工】需要核对的一点：** 「40 位认证数值」依赖 Mathematica 显著性算术给出的误差界。

### A.2 弧长引理

**引理 A2.** 设 0 < ρ < r，x 是平面上任一点。D(x, ρ) ∩ bd D(o, r) 要么为空，要么是一段闭弧，它在 o 处张开的圆心角 ≤ 2 arcsin(ρ/r)。

**证明【人工】.** 圆周上的点 r·e(t) 满足 |r e(t) − x|² ≤ ρ²，等价于 cos(t − t_x) ≥ 常数，所以交集是关于 x 方向对称的一段弧（x = o 时交集为空，因为 r > ρ）。这段弧不可能包含两个对径点，因为它们相距 2r > 2ρ，而 D(x,ρ) 的直径只有 2ρ。所以它是劣弧，圆心角 φ ≤ π。两端点都在 D(x,ρ) 内，弦长 2r sin(φ/2) ≤ 2ρ，于是 φ ≤ 2 arcsin(ρ/r)。∎

- **L-arc1**（ρ = 1）：一个单位圆在 bd D(o,r) 上盖住的弧，圆心角 ≤ A(r) := 2 arcsin(1/r)。上确界在 |ox| = √(r²−1) 时取到（见 `03` 的门 E_max）。
- **L-arc2**（ρ = 2，r > 2）：若三个单位圆有公共点 x，它们的并含于 D(x, 2)，所以它们在 bd D(o,r) 上盖住部分的总角度 ≤ 2 arcsin(2/r)。
- 库函数 `MaxCoveredArc`、`MaxCoveredArcTriple` 实现这两个界（见 `05e` 的门 L-arc1/L-arc2，并有 `wl/tests` 回归测试）。

## B. T1：n = 3, 4, 7（弧计数）

**定理.** R₃ = 2/√3，R₄ = √2，R₇ = 2。

**可达性.** n=3、4 用 `known.json` 中的构型，n=7 用正则环 `RingConfig[6]`（O 加上距 O 为 √3、等角分布的 6 个圆心）。三者都满足 `ExactCoverQ[·, R_n]` = True，而 `ExactCoverQ[·, R_n + 10⁻³⁰]` = False。见 `03` 的门 E_cover3/E_cover4/E_cover7。

**上界【人工】.**
- A(R) = 2arcsin(1/R) 在 R > 1 上严格递减，因为 A′(R) = −2/(R√(R²−1))（`03` E_dec）。而 A(2/√3) = 2π/3，A(√2) = π/2，A(2) = π/3（`03` E_hit，精确）。
- n = 3, 4：设 R > R_n，并且有 n 个圆覆盖 D(0,R)。由 L-arc1，每个圆在 bd 上盖住的角度 ≤ A(R) < A(R_n) = 2π/n，n 个合起来不到 2π，盖不满边界圆，矛盾。
- n = 7：设 R > 2。每个圆盖住的角度 < π/3，所以与 bd D(0,R) 相交的圆至少要 t ≥ 7 个。这些圆的圆心距 O 都大于 R − 1 > 1，所以都盖不住 O（`03` E_step2）。盖住 O 还需要另外一个圆，总数 ≥ 8 > 7，矛盾。∎

## C. T2/T2′：n = 8, 9（10）的无条件最优性（修正后的 [FT] 证明）

### C.0 定理与记号

令 n ∈ {8,9,10}，k = n−1，R = R_n = 1 + 2cos(2π/k)，C_n = D(o,R)。

**定理.** (i) n 个单位圆能覆盖 C_n。(ii) 能覆盖 C_n 的 n 个单位圆，模旋转唯一，就是 `RingConfig[k]`：一个圆与 C_n 同心，其余 k 个圆心位于距 o 为 **2cos(π/k)** 的正 k 边形顶点上（[FT] 把这个距离印成了 2 sin，见 §C.10）。(iii) 半径大于 R 的圆盘不能被 n 个单位圆覆盖。

**函数**（r = R 是参数，0 ≤ α ≤ π）：
- f(α) = 2 arcsin(sin(α/2)/R)，F(α) = (R²/2)(f(α) − sin f(α)) + ½ sin α；
- ᾱ = 6π/k；T(α) = f(ᾱ) + f′(ᾱ)(α − ᾱ) 是 f 在 ᾱ 处的切线；U(α) = F(ᾱ) + F′(ᾱ)(α − ᾱ) 是 F 在 ᾱ 处的切线；
- S(θ) = (R²/2)(θ − sin θ)，即圆心角为 θ 的弓形面积，它在 [0, 2π] 上递增。所以 F(α) = S(f(α)) + ½ sin α。

**已证的函数性质：**
- f″(α) = −(R²−1) sin(α/2) / (2(R² − sin²(α/2))^{3/2}) < 0，这个负号直接看得出来【人工】。所以 f 在 (0,π) 上严格凹，且有 T ≥ f（等号仅在 ᾱ 处）。
- f′(ᾱ) > 0，f(ᾱ) = 2π/k：`08` H3、H4（精确）；切线的值与斜率：`05` E_tangent。
- 对所有 R > 1，F″ < 0 在 (0,π) 上成立：`08` H2（量词消去 `Resolve`）。所以 F 严格凹，且 U ≥ F（等号仅在 ᾱ 处）。

可达性 (i)：`05` 的门 E_ring 给出 `ExactCoverQ[RingConfig[k], R]` = True、`+10⁻³⁰` = False；门 E_typo 给出环的半径 = 2cos(π/k)。

下面 C.1–C.8 证明 (ii)，C.9 由 (ii) 推出 (iii)。从这里起，设 C₀,…,C_{n−1}（圆心 o₀,…,o_{n−1}）覆盖 C_n。

### C.1 第 1 步：反射归一化（[FT] 没有给证明，本仓库 P0）

**命题 P0.** 对每个与 bd C_n 相交的 Cᵢ，若 o 与 oᵢ 分在 Cᵢ、C_n 的根轴两侧，就把 Cᵢ 关于这条根轴反射。
(a) 反射后仍是 C_n 的覆盖；
(b) 反射后每个与边界相交的圆都满足 |o oᵢ| ≤ √(R²−1)；
(c) 若反射后的覆盖是 `RingConfig[k]`，那么原来那组圆中没有一个被反射过。

**证明.** 取坐标使 oᵢ = (0, d)。根轴是直线 y = h，h = (d²+R²−1)/(2d)。o 与 oᵢ 同侧 ⟺ d² ≤ R²−1。oᵢ 的镜像是 (0, d′)，其中 d′ = (R²−1)/d。下面两个恒等式见 `05f` 的门 I2、I3：
|p−oᵢ′|² − |p−oᵢ|² = 2(d−d′)(y−h)；在 bd C_n 上 |p−oᵢ|² − 1 = −2d(y−h)，|p−oᵢ′|² − 1 = −2d′(y−h)。
- (a)【人工】要证 Cᵢ ∩ C_n ⊆ Cᵢ′。根轴下方的点离 oᵢ′ 比离 oᵢ 更近。根轴上方，C_n ∩ {y ≥ h} 是一个弓形，等于它的边界弧的凸包，而这段弧到 oᵢ′ 的距离 ≤ 1。另外，`05f` 的门 Q-a 用 `Resolve` 对一切 R>1、d² > R²−1 判定了这个包含关系为 True。
- (b) d′ < √(R²−1)。被反射的圆仍过原来的两个交点，所以仍与边界相交。
- (c)【人工】反设 C₁ 是反射得到的，它原来的圆心是 ((R²−1)/s, 0)，s = 2cos(π/k)。考虑内部三重点 p = e(−π/k)：它到原来那个圆的距离 > 1，到其余环圆的距离也 > 1（`05f` 的门 U，k = 7,8,9，精确）。把 p 往 C₀、C_k 的外侧推一点点，得到 C_n 中一个没被盖住的点，矛盾。
- 归一化之后每个边界圆满足 |oᵢ| < R，所以 **oᵢ ∈ int C_n**，后面要用到这一点。∎

**αᵢ ≤ π（P0b）** 要等到 C.3 之后才能表述：αᵢ 是胞腔 Dᵢ 的边界弧在 oᵢ 处张开的角。同侧时，这段弧上的点 p 都满足 p_y ≥ h ≥ d，所以从 oᵢ 看过去，弧上所有方向都落在一个闭半平面里，因此 αᵢ ≤ π【人工】（`05f` 的门 Q-b）。

### C.2 第 2 步：结构引理 A（n = 8, 9）

**引理 A.** (a) 恰有一个圆含于 int C_n，记为 C₀，其余 k 个圆都与 bd C_n 相交。(b) 与 bd C_n 相交的圆中，没有三个有公共点。(c) 对每个 i ≥ 1，去掉 Cᵢ 后剩下的圆盖不住 bd C_n。

**证明【人工】.** o 被某个圆盖住，这个圆的圆心距 o ≤ 1，所以它含于 D(o,2) ⊂ int C_n（R > 2）。这说明至少有一个圆在 int C_n 内。
不碰边界的圆对覆盖 bd C_n 没有贡献，所以覆盖 bd C_n 的至多 k 个圆。若只用 k−1 个圆，由 L-arc1，它们盖住的总角度 ≤ (k−1)·2arcsin(1/R)，而 n=8 时 6 arcsin(1/R₈) < π，n=9 时 7 arcsin(1/R₉) < π，总角度不到 2π，盖不满。这一步同时证明了 (a) 和 (c)。
对 (b)：若有三个边界圆共点，由 L-arc2 它们合起来至多盖住 2arcsin(2/R)，其余 k−3 个至多盖住 (k−3)·2arcsin(1/R)；而 4arcsin(1/R₈) + arcsin(2/R₈) < π，5arcsin(1/R₉) + arcsin(2/R₉) < π，总和还是不到 2π。∎

上面四个不等式由 `05e` 用向外舍入区间判定，余量分别是 0.3743、0.1992、0.1520、0.0299。[FT] 把 6arcsin(1/R₈) 的值印成 2.76326081，真值是 2.767326081（数字顺序印错了），不影响结论。

### C.3 第 3 步：结构引理 B（Dirichlet 胞腔复形）

[FT] 只写了一句 "From the considerations above it follows that…"，没有给证明。下面是本仓库补写的证明，**整节【人工】**。

设 Vᵢ 是 oᵢ 的 Voronoi 胞腔（闭凸多边形区域），Dᵢ = Vᵢ ∩ C_n。圆心两两不同：若两个边界圆重合，(c) 不成立；C₀ 与边界圆也不可能重合。

**B0.** Dᵢ ⊆ Cᵢ。理由：x ∈ Dᵢ 被某个 Cⱼ 盖住，所以 |x−oᵢ| ≤ |x−oⱼ| ≤ 1。由此 D₀ ⊆ C₀ ⊂ int C_n。V₀ 是凸集，与 int C_n 相交但不碰 bd C_n，所以 V₀ ⊂ int C_n，D₀ = V₀ 是一个凸多边形，o₀ 在它的内部。

**B1（边界弧）.** 令 aᵢ = Dᵢ ∩ bd C_n（i ≥ 1），Aᵢ = Cᵢ ∩ bd C_n。Aᵢ 是一段圆心角 < π 的闭弧（引理 A2），且 aᵢ ⊆ Aᵢ。
- *aᵢ 有正长度：* 由 (c)，bd C_n ∖ ⋃_{l≠i} C_l 非空，而且在 bd C_n 中是开集。它里面的点只被 Cᵢ 盖住，所以离 oᵢ 最近，都属于 aᵢ。
- *aᵢ 连通：* 设 x, y ∈ aᵢ，z 在 Aᵢ 内 x 与 y 之间，但 z ∉ Dᵢ。那么存在 l，使 |z−o_l| < |z−oᵢ|。开半平面 H = {|·−o_l| < |·−oᵢ|} 含 z，不含 x、y。H ∩ bd C_n 是一段弧，所以它落在 x、y 之间，从而 H̄ ∩ bd C_n ⊆ Aᵢ ⊆ Cᵢ。另一方面，由 (c) 存在 w ∈ bd C_n，它只被 C_l 盖住。于是 o_l 是离 w 最近的圆心，w ∈ H̄ ⊆ Cᵢ，这与「w 只被 C_l 盖住」矛盾。
- *循环排列：* aᵢ ∩ aⱼ 含于中垂线与圆周的交点，最多两个点，所以这 k 段弧只在端点处相接。一个端点不可能同时属于三段弧，否则它到三个边界圆心等距、且距离 ≤ 1，与 (b) 矛盾。因此这 k 段弧按循环顺序首尾相接、拼成整个圆周。把下标排成循环顺序，记 aᵢ = [qᵢ, qᵢ₊₁]。

**B2（内部顶点）.** C_n 中的 Voronoi 顶点到至少三个圆心等距，且这个距离 ≤ 1。由 (b)，这三个圆心中必有 o₀。所以每个顶点都在 D₀ 上，并且恰好是三个胞腔的交点（若是四个，就有三个边界圆共点）。两个边界胞腔 Dᵢ、Dⱼ 之间的公共边，其端点要么是 (0,i,j) 型顶点，要么在 bd C_n 上。(0,i,j) 型顶点至多一个（它是 o₀, oᵢ, oⱼ 的外心）。两端都在 bd C_n 上也不行，那样 aᵢ 与 aⱼ 共享两个端点，只能互补，挤不下其他弧。所以每条这样的边都是一条「辐条」：从 D₀ 的某个顶点 p 出发，到 bd C_n 上的一点 q 结束。

**B3（拼合）.** D₀ 的每个顶点恰好发出一条辐条，这些辐条两两不交，把环形区域 C_n ∖ int D₀ 分成若干块。每块内部不再有 Voronoi 边，所以只属于一个胞腔。反过来，每个边界胞腔的内部是凸的、连通的，又含正长度的边界弧，所以恰好占一块。由此，块数 = k，D₀ 是 k 边形，顶点记为 p₁,…,p_k；**Dᵢ 是由线段 pᵢpᵢ₊₁、pᵢ₊₁qᵢ₊₁、pᵢqᵢ 和弧 qᵢqᵢ₊₁ 围成的曲边四边形**，与正则构型的胞腔复形同构。最后，oᵢ ∈ Vᵢ ∩ int C_n ⊆ Dᵢ（用到 C.1 的归一化）。∎

**n = 10.** 引理 A 的 (a)、(c) 等价于「9 个边界圆中任意 8 个盖不住 bd C₁₀」，再加上 (b)。这正是 [FT] §3 证明的内容（转述 Melissen 1997 的论证，见 §C.11）。B1–B3 只用到 (a)(b)(c)，所以对 n = 10 照搬成立。

### C.4 第 4 步：角量、剖分、恒等式 (1)(2)

定义角量（o 是 C_n 的圆心）：
αᵢ = ∠qᵢoᵢqᵢ₊₁（经过胞腔一侧量取），βᵢ = ∠pᵢoᵢqᵢ，γᵢ = ∠pᵢ₊₁oᵢqᵢ₊₁，δᵢ = ∠pᵢoᵢpᵢ₊₁，εᵢ = ∠pᵢo₀pᵢ₊₁，θᵢ = ∠qᵢoqᵢ₊₁。

**【人工】：**

### C.5 第 5 步：单格张角界 θᵢ ≤ T(αᵢ)，并推出 ᾱ ≤ α

单格的几何：oᵢ 距 o 为 sᵢ，R−1 ≤ sᵢ ≤ √(R²−1)（下界是因为 Cᵢ 与边界相交，上界由 C.1 保证）。|oᵢqᵢ| ≤ 1，|oᵢqᵢ₊₁| ≤ 1（由 B0）。

[FT] 写的是 θᵢ ≤ f(αᵢ)（G1），但这个界**在 αᵢ < π/3 时不成立**。原因是 Dirichlet 顶点 qᵢ 只满足 |oᵢqᵢ| ≤ 1，不一定等于 1。浮点反例的余量为 +0.085（`experiments/2026-10-01-fejes-toth-audit`）。所以这里改证切线界 θᵢ ≤ T(αᵢ)，后面的 (3) 只需要这个更弱的界。

- **情形 αᵢ ≥ π/3【人工 + `08` H1】.** 弦长 c = |qᵢqᵢ₊₁| 满足 c² = a² + b² − 2ab cos αᵢ，其中 a, b ≤ 1。在 cos αᵢ ≤ ½ 时，有 c² ≤ 2 − 2cos αᵢ（H1 用 `Resolve` 对所有 a, b, cos α 判定）。又因为弧 qᵢqᵢ₊₁ ⊆ Aᵢ，θᵢ ≤ π，所以 c = 2R sin(θᵢ/2)。由此 θᵢ ≤ f(αᵢ) ≤ T(αᵢ)。
- **情形 αᵢ ≤ ᾱ【`05b-g1t-small-alpha.wls`】.** 这里的参数化是：oᵢ = (s,0)，弧端点为 R e(t_j)，u_j = R e(t_j) − (s,0)，参数域 Ω = {s ∈ [R−1, √(R²−1)], |u_j| ≤ 1, α ≤ ᾱ}。证书在整个 Ω 上证明 M := cos θ − cos T(α) ≥ 0。Ω 被分成四块无缝覆盖：P1（T ≥ f）、BF（边界面 |u₁| = |u₂| = 1 上 θ = f(α)，精确判定）、Pcollar（正则环附近 ±1/160 的邻域内，用一阶梯度符号论证）、Pbb（其余部分做向外舍入的区间分支定界，下界最小值为 +4.7e−8、+1.2e−9、+1.8e−7）。由于 T 在 [0,π] 上单调增且取值在 (0,π) 内，M ≥ 0 ⟺ θ ≤ T(α)。
  **【人工】需要核对的一点：** Ω 是否就是 C.4 中单格的参数化。具体是：|u_j| ≤ 1 对应 a, b ≤ 1；α 是 u₁ 与 u₂ 的夹角；θ = t₂ − t₁。
- ᾱ ≥ 2π/3 > π/3，所以两个情形合起来覆盖了 [0, π]。

**推论 (3′).** 2π = Σθᵢ ≤ ΣT(αᵢ) = k·T(α)，其中 α := Σαᵢ/k。因为 T(ᾱ) = f(ᾱ) = 2π/k，且 T 的斜率 f′(ᾱ) > 0，所以 **α ≥ ᾱ**。T 是线性的，这一步不需要 Jensen。

### C.6 第 6 步：面积界 (4)(5)(6′)

- **(4)【人工】.** a(Tᵢ) + a(Tᵢ*) = |o₀pᵢ||o₀pᵢ₊₁| sin εᵢ ≤ sin εᵢ，因为由 B0，|o₀p| ≤ 1。sin 在 [0,π] 上凹，由 Jensen 得 Σ ≤ k sin(2π/k)。
- **(5)【人工】.** a(Tᵢ⁻) = ½|oᵢpᵢ||oᵢqᵢ| sin βᵢ ≤ ½ sin βᵢ，Tᵢ⁺ 同理。对 **2k** 个正弦项用 Jensen：
  Σ(a(Tᵢ⁻)+a(Tᵢ⁺)) ≤ ½·2k·sin(Σ(βᵢ+γᵢ)/(2k)) = **k sin((k−1)π/k − α/2)**。
  [FT] 印的是 (n−1) sin(Σ(βᵢ+γᵢ)/(n−1))，分母少了因子 2，见 §C.10。
- **(6′) 引理 G2′：a(Rᵢ) ≤ U(αᵢ)。** [FT] 用的是 a(Rᵢ) ≤ F(αᵢ)（G2）再加 Jensen。在本仓库，G2 此前只有浮点证据（L1）；这里改用切线 U，并给出完整证明：
  - 面积公式【人工】：以 o 为极点、对 Rᵢ 的边界用 Green 公式，得 a(Rᵢ) = S(θᵢ) + τ，其中 τ 是三角形 oᵢqᵢqᵢ₊₁ 的有向面积，|τ| = ½ab sin αᵢ（a = |oᵢqᵢ|，b = |oᵢqᵢ₊₁|，都 ≤ 1）。
  - 情形 αᵢ ≥ π/3：由 C.5 得 θᵢ ≤ f(αᵢ)，而 S 递增，所以 a(Rᵢ) ≤ S(f(αᵢ)) + ½ sin αᵢ = F(αᵢ) ≤ U(αᵢ)。最后一步用到 F 凹（`08` H2）。
  - 情形 αᵢ < π/3：Rᵢ 中的点都形如 oᵢ + t·e(φ)，其中 t 不超过射线到 bd C_n 的距离 ρ(φ)。弧 aᵢ ⊆ Cᵢ，所以 ρ(φ) ≤ 1，即 Rᵢ 含于以 oᵢ 为心、半径 1、张角 αᵢ 的扇形，a(Rᵢ) ≤ αᵢ/2。而 **U(α) > α/2 在 [0, π/3] 上严格成立**：两边都是线性函数，只需检查端点（`08` H6，有理区间判定）。n = 8, 9, 10 时，U(0) 分别为 1.441、1.070、0.804，U(π/3) − π/6 分别为 0.555、0.329、0.184。∎
  - U 是线性的，所以 Σa(Rᵢ) ≤ ΣU(αᵢ) = k·U(α)，这一步也不需要 Jensen。

### C.7 第 7 步：求和与收尾

由剖分以及 (4)(5)(6′)：

  π R² = Σ(a(Tᵢ)+a(Tᵢ*)+a(Tᵢ⁻)+a(Tᵢ⁺)+a(Rᵢ)) ≤ k·G(α)，其中 G(α) = sin(2π/k) + sin((k−1)π/k − α/2) + U(α)。

- 因此 G 在 [ᾱ,π] 上严格递减。由 C.5，α ≥ ᾱ，所以 k·G(α) ≤ k·G(ᾱ)。

于是整条链两端都是 πR²，链中每个不等号都取等号。

### C.8 第 8 步：取等 ⟹ 构型就是 `RingConfig[k]`【人工 + `08` H8】

- (6′) 逐格取等。若 αᵢ < π/3，则 a(Rᵢ) ≤ αᵢ/2 < U(αᵢ)，不可能取等。所以 αᵢ ≥ π/3，且 F(αᵢ) = U(αᵢ)。F 严格凹，所以 **αᵢ = ᾱ**。再由 a(Rᵢ) = F(αᵢ) 推出 ab = 1，即 **|oᵢqᵢ| = |oᵢqᵢ₊₁| = 1**。

### C.9 第 9 步：(iii) 更大的圆盘盖不住【人工】
