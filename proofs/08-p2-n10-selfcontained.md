## 1. 第一部分：任意 8 个圆盖不住 bd C₁₀

由此推出 (I)：盖住 o 的圆若碰界则 |oⱼ| ≥ R−1 > 1，盖不到 o，故至少一个内部圆；若有两个内部圆，其余 8 个盖住 bd C₁₀，矛盾。

设（反证）bd C₁₀ ⊆ C₀ ∪ … ∪ C₇。令 U = C₁₀ ∖ (C₀∪…∪C₇)。因 C₀,…,C₉ 覆盖 C₁₀ 且圆盘闭，**cl U ⊆ C₈ ∪ C₉**。

**1.1 [手证] 极小性.** 由 N1，任意 7 段弧盖不住圆周，故 8 个圆都碰界，且每段 Aⱼ 有「私有点」πⱼ（不被其余弧覆盖）。按 πⱼ 的环向顺序重新编号。每段 Aⱼ ⊂ (πⱼ₋₁, πⱼ₊₁)（开弧），于是开弧 (πⱼ, πⱼ₊₁) 只能被 Aⱼ、Aⱼ₊₁ 覆盖，故 **Aⱼ ∩ Aⱼ₊₁ ≠ ∅**，且任一段不含另一段。

**1.2 [手证] 无三圆共点.** 若 C₀…C₇ 中三圆共点，由 (E1) 它们盖的弧 ≤ 2 arcsin(2/R)，其余 5 圆 ≤ 10 arcsin(1/R)，合计 < 2π（N2），矛盾。

**1.3 [手证] 重叠点 qᵢ.** 取 qᵢ ∈ Aᵢ₋₁ ∩ Aᵢ。由 1.1–1.2，这些重叠弧两两不交，q₁,…,q₈ 环向有序，相邻步长 ∠qᵢoqᵢ₊₁ ∈ (0, 2 arcsin(1/R)]（两点都在 Cᵢ 内），总和为 2π。

**1.4 [手证] 内交点 pᵢ ∈ C₈∪C₉.** 令 e、f 为 Aᵢ 的起点与终点，γᵢ = bd Cᵢ ∩ C₁₀ 为 Cᵢ 圆周上从 e 到 f 的内弧。e ∈ Cᵢ₋₁（Aᵢ 的起点落在重叠里），f ∉ Cᵢ₋₁（否则 f ∈ Cᵢ₋₁∩Cᵢ∩Cᵢ₊₁，违反 1.2）。令 **pᵢ = γᵢ 上（从 e 走向 f）最后一个属于 Cᵢ₋₁ 的点**。则 pᵢ ≠ f，pᵢ ∈ bd Cᵢ₋₁ ∩ bd Cᵢ ∩ C₁₀。取 γᵢ 上 pᵢ 之后、靠近 pᵢ 的点 y：y ∈ int C₁₀，y ∉ Cᵢ₋₁；pᵢ 不属于其他 Cⱼ（1.2），所以 y 也不属于；把 y 沿 y−oᵢ 方向往外推一点就离开 Cᵢ。所以 **pᵢ ∈ cl U ⊆ C₈ ∪ C₉**。

**1.5 [手证 + N4–N6] 角度.** 记 Δ(x→y) ∈ (−π,π] 为从 x 到 y 的有向小角。对路径
p_i → q_{i+1} → q_{i+2} → p_{i+3} → q_{i+4} → q_{i+5} → q_{i+6} → q_{i+7} → p_i，
每一步的两端点同在某个圆内（依次为 C_i, C_{i+1}, C_{i+2}, C_{i+3}, C_{i+4}, C_{i+5}, C_{i+6}, C_{i+7}=C_{i−1}），由 (E2)，含 p 的步长绝对值 ≤ arcsin(2/R)，两端都在 bd 上的步长 ≤ 2 arcsin(1/R)。
- *伸缩求和.* 每个含 p 的步长等于对应的 q 步长加上修正 Δ(pⱼ→qⱼ) 或 Δ(qⱼ→pⱼ)（|修正| ≤ arcsin(2/R)；由 N6，两者之和 < π，所以有向小角的等式在 ℝ 中精确成立，不只是模 2π）。修正项两两抵消，所以全路径步长和 = Σ q 步长 = 2π。
- 短程 S（前三步）≤ 2 arcsin(2/R)+2 arcsin(1/R)；长程 ≤ 2 arcsin(2/R)+6 arcsin(1/R)，所以 S = 2π − 长程 ≥ ψ_min。故 S ∈ [ψ_min, 2π−ψ_min]，从而 **cos∠pᵢopᵢ₊₃ ≤ cos ψ_min < 0**。
- 同理，pᵢ 与 pᵢ₊₄ 之间两侧各 ≤ 2 arcsin(2/R)+4 arcsin(1/R) = 2π−ξ_min，故 **cos∠pᵢopᵢ₊₄ ≤ cos ξ_min < 0**。

**1.6 引理 B（替代 [FT] 的「对称位置」断言）.** 设 D₁、D₂ 是两个单位圆，p ∈ bd D₁ ∩ bd D₂，ρ = |p|。它们在 bd C₁₀ 上的弧（以 p 的方向为 0 度）为 [a₁,b₁]、[a₂,b₂]，且 a₁ < a₂ ≤ b₁ < b₂，并集测度 ϑ = b₂−a₁。则对 ρ ∈ [3/4, ρ_top]，
```
ϑ ≤ H(ρ) := 4 arctan( 2√(1−(R−ρ)²/4) / (R+ρ) ),
```
其中 ρ_top = 1.742227… 是两弧都取最大值 2 arcsin(1/R) 的对称构型，满足 H(ρ_top) = 4 arcsin(1/R)（证书 B0′，`RootReduce` 精确）。H 就是 [FT] h(ϑ) 的反函数。注意本引理**不需要**「p 是内交点」这一条件。

*证明.* 对过 p 的单位圆，以 X_x = R e^{ix} 为**起点**的那个是唯一的；记它的终点为 β(x)（β = β_ρ）。
- 所有被覆盖的点都在 D(p,2) 内，所以 β ≤ a_max := arccos((R²+ρ²−4)/(2Rρ))。令 D\* 为圆心在 p 与 R e^{i·a_max} 中点的圆，s\* 为它的起点，则 β(s\*) = a_max。
- 由镜像（关于直线 op）得 −a₁ = β(−b₁)，又 b₂ = β(a₂)，所以 ϑ = β(u)+β(v)，其中 u = a₂，v = −b₁，u+v ≤ 0。
- 需要的三条性质：
  - (i) β 在 [−a_max, 0] 上不减。用圆心方向参数 τ（圆心 = p+e^{iτ}）表示，终点 b(τ) 满足 b′ > 0 于 (−τ_B, τ_B)；由镜像 a(τ) = −b(−τ)，所以起点 a(τ) 也严格增。证书 B1：b′>0 于 [−τ_B, (15/16)τ_B]，b″<0 于 [(15/16)τ_B, τ_B]；且 b′(τ_B) = 0（b 在 τ_B 处取最大值 a_max，是内部光滑极大）。
  - (ii) φ(x) := β(x)+β(−x) ≤ φ(0) = 2β(0) 于 [0, s\*]。证书 B2：φ″<0 于 [0,1/16]，φ′<0 于 [1/16, s\*]，并带守卫条件 |X−p| < 2、「X 是起点」。φ(x) 就是过 p 与 X_x 的两个单位圆并集的跨度，所以这一条正是 [FT] 的「对称位置极小」。
  - (iii) 2β(0) = H(ρ)：证书 B0 精确验证。
- 不妨设 u ≤ v，分三种情况：
  - v ≤ 0：由 (i)，β(u)+β(v) ≤ 2β(0)。
  - 0 < v ≤ s\*：u ≤ −v，由 (i) 得 β(u)+β(v) ≤ φ(v)，再由 (ii) ≤ 2β(0)。
  - v > s\*：β(v) ≤ a_max = β(s\*)，β(u) ≤ β(−s\*)，所以和 ≤ φ(s\*) ≤ 2β(0)。∎

*应用于 pᵢ.* 令 ϑᵢ = |Aᵢ₋₁ ∪ Aᵢ|。则 ϑ₁+ϑⱼ ≥ 2π − 8 arcsin(1/R)（这里是 ≥：其余 4 个圆至多盖 8 arcsin(1/R)），且 ϑⱼ ≤ 4 arcsin(1/R)，所以每个 ϑ ≥ ϑ_lo := 2π − 12 arcsin(1/R)。
- 若 ρᵢ < 3/4：由 (E1)/(E2)，ϑᵢ ≤ 2a_max(ρᵢ) ≤ 2a_max(3/4) < ϑ_lo（a_max 在 [R−2, √(R²−4)] 上递增；证书 B4），矛盾。所以 ρᵢ ≥ 3/4。
- 令 ρ̂ᵢ = min(ρᵢ, ρ_top) ∈ [3/4, ρ_top]。由引理 B（ρᵢ ≥ ρ_top 时直接由 ϑᵢ ≤ 4 arcsin(1/R) = H(ρ_top)），ϑᵢ ≤ H(ρ̂ᵢ)。
- H 在 [3/4, ρ_top] 上凹（B3），所以 2π − 8 arcsin(1/R) ≤ H(ρ̂₁)+H(ρ̂ⱼ) ≤ 2H(m)，其中 m = (ρ̂₁+ρ̂ⱼ)/2。
- H 在 [3/4, 59/50] 上递增，且 H(59/50) < π − 4 arcsin(1/R)（B3、B4），所以 **m ≥ 59/50**。

**1.7 距离与矛盾.** 由 1.5，|pᵢpᵢ₊₃|² ≥ ρ̂₁²+ρ̂ⱼ²−2ρ̂₁ρ̂ⱼ cos ψ_min。右边开方是一个范数（|cos ψ_min|<1），凸且对称，所以 ≥ 2m sin(ψ_min/2) ≥ 2·(59/50)·sin(ψ_min/2) = **2.0023 > 2**（B5）。同理 **|pᵢpᵢ₊₄| ≥ 2.3328 > 2**。
- 直径为 2 的单位圆不能同时含 pᵢ 与 pᵢ₊₃ 或 pᵢ₊₄；循环距离 5 等价于 3，所以也不能同时含 pᵢ 与 pᵢ₊₅。
- 于是 C₈（以及 C₉）所含的 p 的下标集合两两循环距离 ≤ 2，这样的集合至多 3 个元素（N7，穷举 Z₈ 的全部子集）。两个圆至多含 6 < 8 个 pᵢ，与 1.4 矛盾。∎（第一部分）

## 2. 第二部分：九个碰界圆的胞腔无三者共点

由第一部分，C₀ ⊂ int C₁₀，C₁,…,C₉ 都碰界。用 `proofs/06` P0（反射约定，证书 `05f`，对一切 R>1 成立）可设各 oᵢ 与 o 同侧，从而 oᵢ ∈ int C₁₀，所以 oᵢ ∈ Dᵢ，且 Dᵢ 凸、关于 oᵢ 星形；又 Dᵢ ⊆ Cᵢ，并且 αᵢ ≤ π。

**2.1 [手证] 弧的结构.** 每个 Dᵢ ∩ bd C₁₀ 非空，否则其余 8 个圆盖住 bd，与第一部分矛盾。每个 Dᵢ ∩ bd C₁₀ 也是连通的：
- 设它有两个分支，夹着一段开弧 G ⊂ Aᵢ。弦 e₁e₂ ⊂ Dᵢ（Dᵢ 凸），把 C₁₀ 切出 G 上方的弓形。
- 任何 Dₖ（k ≠ i）若在 G 内和 G 外都有点，连接这两点的线段会横穿这条弦。可是 Dᵢ ∩ Dₖ 只在一条平分线上，内部不交，所以不可能。
- 因此 G 中的胞腔整个落在 G 内，被 Cᵢ 覆盖；去掉这些胞腔对应的圆（以及 C₀），剩下 ≤ 8 个圆仍盖住 bd，矛盾。

于是 9 段弧按环向排列，相邻两段交于 qᵢ。

**2.2 [手证 + N2] 式 (8)：Cᵢ ∩ Cᵢ±ⱼ = ∅（j=3,4）.**
- 若 x ∈ Cᵢ ∩ Cᵢ₊ⱼ，则 Aᵢ、Aᵢ₊ⱼ 都在弧 W = D(x,2) ∩ bd 内，|W| ≤ 2 arcsin(2/R) < π。
- W 含 Aᵢ 与 Aᵢ₊ⱼ 之间的一侧间隙；圆周的其余部分由另一侧的 j−1 段弧或 8−j 段弧覆盖，至多 5 段。
- 所以 2π ≤ 2 arcsin(2/R) + 10 arcsin(1/R)，与 N2 矛盾。
- 推论：任意三个相交的胞腔下标相邻。

**2.3 [手证 + N3] 情形划分.**
- 两个不相交的三元组会导致 2π ≤ 4 arcsin(2/R) + 6 arcsin(1/R)，与 N3 矛盾。
- 若 {D₁,D₂,D₃} 与 {D₂,D₃,D₄} 都相交：两个三重点都在边 D₂∩D₃ 上，而这条边的相对内部只属于两个胞腔，所以两点重合，推出 D₁ ∩ D₄ ≠ ∅，与 (8) 矛盾。
- 所以只剩 [FT] 的 Case 1（仅 D₁D₂D₃）与 Case 2（D₁D₂D₃ 与 D₃D₄D₅）。
- 边 D₁|D₃ 的另一端，由 (8) 只能是 D₀。

**2.4 剖分 [手证].** 每个胞腔从 oᵢ 作锥形剖分；跨公共直边的两块三角形关于该边互为镜像（边在 oᵢoₖ 的中垂线上）。按 [FT] 的分组，C₁₀ 被不重叠地剖分为 P₁、P₂（Case 2 还有 P₃）、S₁（S₂）、Qᵢ、Rᵢ。

**2.5 各块的面积界.**
- **(9)/(9′)** a(P₁) = Σ|o₀pⱼ||o₀pⱼ₊₁| sin εⱼ ≤ Σ sin εⱼ ≤ 8 sin(π/4)（7 sin(2π/7)）。理由：pⱼ ∈ D₀ ⊆ C₀，Σεⱼ = 2π，o₀ ∈ D₀，εⱼ ∈ [0,π]，最后一步用 sin 的 Jensen 不等式。
- **(10) 引理 P.**
  - P₂ = q₂o₁p₃o₃q₃ 的四条边 ≤ 1（q₂, p₃ ∈ D₁ ⊆ C₁ 等），第五边 |q₂q₃| ≤ 2（q₂, q₃ ∈ C₂）。
  - 以 p₃ 为顶点作扇形三角剖分，令 d₁ = |p₃q₂| = 2 sin u，d₂ = |p₃q₃| = 2 sin w。
  - 两块等腰三角形各 ≤ ½ sin 2u、½ sin 2w；中间三角形 ≤ T₂（若 d₁²+d₂² ≤ 4 取直角，否则受 |q₂q₃| ≤ 2 约束，取 Heron(d₁,d₂,2)）。
  - 证书 P：在 [0,π/2]² 上 ≤ 2.28458（489 盒）。数值上真最大值为 2.2845429（圆内接 1,1,1,1,2），比 [FT] 印的 2.284572282 略紧。反向对照：把阈值设为 2.28454 时，B&B 不闭合。
- **(11)** a(S) ≤ (R²/2)(θ−sin θ)，θ = 2 arcsin(1/R)（弦 ≤ 2）。
- **(12)** a(Qᵢ) = 2·½|oᵢp||oᵢq| sin(∠) ≤ 1。
- **(13)/(13′) 引理 L（替代用到 G1 的 Jensen）.** 令 seg(θ) = (R²/2)(θ − sin θ)。对一个边界胞腔（|oᵢq|, |oᵢq′| ≤ 1，αᵢ ≤ π），有 a(Rᵢ) ≤ seg(θᵢ) + ½|oᵢq||oᵢq′| sin αᵢ。
  - 弦长 |qq′|² = a²+b²−2ab cos α 在 [0,1]² 上是凸的，最大值在顶点取到 = max(1, 4 sin²(α/2))。所以 α ≥ π/3 时 θ ≤ f(α)，从而 a(R) ≤ F(α)；α < π/3 时 θ ≤ θ_c := 2 arcsin(1/(2R))。
  - 取 a\* 使 f(a\*) = (2π − x_max)/N。Case 1：N=8，x_max = 2 arcsin(1/R)，a\* = a₀ = 2.028453…；Case 2：N=7，x_max = 4 arcsin(1/R)，a\* = b₀ = 1.948256…。令 μ = −F′(a\*)/f′(a\*) > 0，Φ = F + μf。
  - α ≥ π/3 时：a(R)+μθ ≤ Φ(α) ≤ Φ(a\*)。依据：Φ 在 [π/3,π] 上凹（L0：f″<0，F″<0），且 Φ′(a\*) = 0。
  - α < π/3 时：a(R)+μθ ≤ seg(θ_c) + μθ_c + √3/4 < Φ(a\*)（余量 0.228 / 0.180）。
  - 对 N 个格求和，并用 Σθᵢ = 2π − x ≥ N f(a\*)，得 **Σa(Rᵢ) ≤ N F(a\*)**，数值为 4.92397937 / 4.33229538，与 [FT] (13)(13′) 印刷数一致。
