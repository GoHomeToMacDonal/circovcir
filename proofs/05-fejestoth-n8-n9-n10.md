## 1. 定理与构型

**定理（[FT]）.** n ∈ {8, 9, 10} 时 R_n = 1 + 2cos(2π/k)，k = n−1，最优覆盖唯一，等于「D(0,1) + k 个圆心在距 O 为 **2cos(π/k)** 处、等角分布的单位圆」。

| n | k | R_n（20 位） |
|---|---|---|
| 8 | 7 | 2.2469796037174670611 |
| 9 | 8 | 2.4142135623730950488（= 1+√2）|
| 10 | 9 | 2.5320888862379560704 |

**可达性（L3）.** `ExactCoverQ[RingConfig[k], RingRadius[k]]` = True，`+10⁻³⁰` = False（证书 `E_ring`，精确判定）。即正则环精确覆盖 D(0, R_n) 且是紧的。这一侧与 `01` 的 L3 结论一致，n=8,9,10 的**最优值本身**（而非最优性）已是 L3。

**笔误更正（已验证，L3）.** [FT] 定理陈述把外环圆心到 O 的距离印成 `2 sin π/(n−1)`，应为 **`2 cos π/(n−1)`**。证书 `E_typo`：`RingConfig[k]` 的点模长精确等于 `2 Cos[Pi/k]`，且 `2 Cos[Pi/k] ≠ 2 Sin[Pi/k]`。n=8 时 2 sin(π/7)=0.868 与 r_8=2.247 不符，2 cos(π/7)=1.802 才对。

## 2. 证明骨架（[FT] §2–§3）与它为什么不走 H_k

[FT] 的引理只给出「最优覆盖里**恰有一个**圆盘落在 int C_n 内（不碰 ∂C_n）」，但**不**给出它与 C_n 同心。所以不能像 `01` 那样直接套"中心圆恰为 D(0,1)"的弧长论证。[FT] 改用**面积论证**：对覆盖做 Dirichlet（最近圆心）胞腔剖分，对每个碰到 ∂C_n 的胞腔建立单格不等式，再用 Jensen 求和。

记一个边界胞腔：圆心 o_i=(s,0)，R−1 ≤ s ≤ √(R²−1)（根轴同侧约定 S0），胞腔在 ∂C_n 上截出端点 q, q′，内角 α_i = ∠q o_i q′，对应 O 处的张角 θ_i = ∠q O q′。关键函数：

- f(α) = 2 arcsin( sin(α/2) / R )  —— 单格把 α 换算成 θ 的上界（弦长界）。
- F(α) = (R²/2)(f(α) − sin f(α)) + sin(α)/2  —— 单格面积界。
- ᾱ = 6π/(n−1) = 6π/k  —— 正则环对应的 α（取等点）。

## 4. Jensen 链（S4，已复现 — L3）

[FT] §2 的求和链 (1)–(7) 把每个边界胞腔的面积界加总，收尾时用到一个单变量函数的单调性。原文 (364–367 页) 的实际写法（逐式转录，非转写）：

- (1) ΣδᵢΣεᵢ = 2π = Σδ̄ᵢ = Σε̄ᵢ（Tᵢ 与 Tᵢ* 全等）。
- (2) Σ(βᵢ+γᵢ) = (n−1)·2π − Σ(αᵢ+δᵢ) = (n−2)·2π − Σαᵢ。
- (3) 2π = Σ∠qᵢoqᵢ₊₁ ≤ Σf(αᵢ) ≤ (n−1)f(Σαᵢ/(n−1))，故 **Σαᵢ ≥ (n−1)·f⁻¹(2π/(n−1)) = (n−1)·(6π/(n−1)) = Σᾱᵢ**（用到 f(6π/(n−1))=2π/(n−1)，即 E_fbar）。
- (4) Σ(a(Tᵢ)+a(Tᵢ*)) ≤ Σ sin εᵢ ≤ (n−1) sin(Σεᵢ/(n−1))。
- (5) Σ(a(Tᵢ⁻)+a(Tᵢ⁺)) ≤ **½·Σ(sin βᵢ + sin γᵢ)** ≤ (n−1) sin(**Σ(βᵢ+γᵢ)/(n−1)**)。
- (6) Σ a(Rᵢ) ≤ Σ F(αᵢ) ≤ (n−1) F(Σαᵢ/(n−1))。
- 记 α = Σαᵢ/(n−1)。由 (2)，Σ(βᵢ+γᵢ)/(n−1) = 2(n−2)π/(n−1) − α。代入 (5)+(6)：
  Σ(a(Tᵢ⁻)+a(Tᵢ⁺)+a(Rᵢ)) ≤ (n−1)·[ sin(2(n−2)π/(n−1) − α) + F(α) ]。
- (7) [FT] 原文："The function `sin(2(n−2)π/(n−1) − α) + F(α)` is concave for 0 ≤ α ≤ π and, as it can be checked numerically, **decreasing for α = 6π/(n−1)**. Therefore it is decreasing for 6π/(n−1) ≤ α ≤ π." 由 α ≥ ᾱ=6π/(n−1)（第 (3) 式）与此单调性，RHS 在 α=ᾱ 取最大，等于正则环的对应面积和 ⟹ 全链取等 ⟹ 构型全等。

**转写修正（本篇的核心更正）.** `02` 与旧证书把 (7) 的函数字面记作 `g(α)=sin(2(n−2)π/(n−1) − α)+F(α)`，在 ᾱ 处求导得 g′(ᾱ)= **+0.55 / +0.79 / +0.85 > 0**，与"递减"相反。原因不是符号或 F 的定义（已逐项核对 [FT] 印出的 f′、F′，与本仓库 `f`、`F` 符号恒等），而是 **(5) 的 Jensen 平均项数**：½Σ(sin βᵢ+sin γᵢ) 是对 **2(n−1)** 个 sin 项做 Jensen，正弦的宗量应是 Σ(βᵢ+γᵢ)/(**2**(n−1)) = (n−2)π/(n−1) − **α/2**，而非 Σ(βᵢ+γᵢ)/(n−1)。[FT] 的排版（经本仓库从 PDF 提取）在这一步把分母 2(n−1) 的因子 2 连同 α 的 ½ 一起丢了，字面读成 `2(n−2)π/(n−1) − α`。**正确函数**是

> **g(α) = sin( (n−2)π/(n−1) − α/2 ) + F(α)**。

两条独立验证说明这才是原文真意：
1. **(7) 端点恒等**：正则环处 β̄=γ̄=(n−5)π/(n−1)，面积和的 sin 项应为 ½(sin β̄+sin γ̄)=sin β̄。修正 g 满足 g(ᾱ)=sin β̄ + F(ᾱ) **精确成立**；字面版给出 sin(2β̄)+F(ᾱ) ≠ sin β̄+F(ᾱ)（n=8: 0.943 vs 1.484），自相矛盾。
2. **单调性**：修正 g 在 ᾱ 处 **g′(ᾱ) < 0**，与 [FT] 的"decreasing at ᾱ"一致。

**证书复现（`E_jensen`，GATING，L3）.** `proofs/certificates/05-fejestoth-n8-n9-n10.wls`：
- (7) 端点：`Simplify[g(ᾱ) − (sin β̄ + F(ᾱ))] === 0`（精确，三 n 全 True）。
- (A) `g′(ᾱ) < 0`：精确符号判定（闭式，如 n=8 为 (−cos(π/7)+sin(π/14)(−1+2cos²(π/14)√(2/(5−cos(π/7)−4sin(π/14)+8sin(3π/14)))))/2 = −0.45727…）。n=8/9/10 分别 **−0.45727 / −0.20711 / −0.0055722**（40 位）。
- (B) `g″(α) < 0 ∀α∈[ᾱ,π]`：区间算术（WL `Interval`，向外舍入 10⁻²⁵，200 个均匀面板），三 n 全部 0 个面板失败。
- (A)+(B) ⟹ g′(α) ≤ g′(ᾱ) < 0 ⟹ **g 在 [ᾱ,π] 严格递减**，正是 [FT] (7) 所需。这把 [FT] 仅称"数值可验"的那一步升到**向外舍入区间证书 L3**（整段区间，而非仅 ᾱ 一点）。

## 4c. 取等 ⟹ 构型全等（S5，刚性事实 — L3；定理 L4-条件）

**命题（S5）.** 当 n∈{8,9,10} 的覆盖精确取到 R_n = 1+2cos(2π/k)（k=n−1）时，最优构型模旋转唯一，等于 D(0,1) 加 k 个在距 O 为 2cos(π/k) 处等角分布的单位圆（`RingConfig[k]`）。这是无条件 L4 的最后一关。

**它不是零维代数系统.** 对比 `proofs/07` 的 n=11 **局部**最优性确实归约为 22×22 KKT 盒并用 Krawczyk 封；S5 的唯一性来自**等号情形的刚性** —— 严格凹 Jensen（(3)、(6)）与严格单格界（G1T、G2）各自把每个胞腔钉死到正则胞腔，不留残余自由参数。因此 S5 **没有新的自由系统可 Krawczyk**，装饰性的 KKT 证书无增量，故**不配**。证书的职责是把「等号 ⟹ 各参数相等 / 接触被迫」所依赖的**严格性事实**做成有限、向外舍入 / RootReduce 精确的数。
