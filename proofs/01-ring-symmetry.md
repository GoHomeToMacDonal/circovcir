# 01 — 弧覆盖公式与"中心圆 + 外环"的对称性（n = 7, 8, 9, 10）

状态：**L4（条件命题，假设 H_k 见下）**，证书 `proofs/certificates/01-ring-symmetry.wls`（exit 0）。证明尚待人工复核。
工具：`wl/CirCovCir.wl`（`CoveredArc`、`MaxCoveredArc`、`RingAlpha`、`RingRadius`、`RingConfig`）与 `src/circovcir/arcs.py`（同名 snake_case）。

## 1. 弧覆盖公式 ω

**引理 1.** 设单位圆盘圆心到 O 的距离为 d > 0，圆 Γ_r = {|x| = r}。Γ_r 落在该圆盘内的部分是一段以圆心方向为中点的闭弧，其圆心角为

ω(r, d) = 2 arccos( (r² + d² − 1) / (2rd) )，

自变量截断到 [−1, 1]：r + d ≤ 1 时 ω = 2π（整圆），|r − d| ≥ 1 时 ω = 0（含相切时退化为一点，测度 0）。

*证明.* Γ_r 上与圆心方向夹角 θ 的点到圆心距离平方为 r² + d² − 2rd cos θ ≤ 1 ⟺ cos θ ≥ (r² + d² − 1)/(2rd)。cos 在 [0, π] 上递减，所以解集是 |θ| ≤ arccos(·)，即一段关于圆心方向对称的弧。∎

**推论.** (a) r = 1：ω(1, d) = 2 arccos(d/2)，d ∈ (0, 2)。
(b) r > 1 固定时，ω 在 d = √(r² − 1) 取最大值 A(r) := 2 arcsin(1/r)，此时 Γ_r 的弦长为 2，恰好是单位圆的直径。对 d 求导即得：自变量的导数为 (d² − r² + 1)/(2rd²)，在 d² = r² − 1 处变号。

## 2. α 关于 β 的函数

设一个圆盘覆盖单位圆 Γ_1 上 β ∈ (0, π) 的弧。由推论 (a) 有 d = 2cos(β/2)，代入引理 1 得到它在 Γ_R 上覆盖的弧 α = f_R(β)：

cos(α/2) = x(u) := a·sec u + b·cos u,  u = β/2,  a = (R² − 1)/(4R),  b = 1/R。

记 β₀ = 2 arccos(min(1, √(R² − 1)/2))（对应 d² = R² − 1），β₁ = 2 arccos((R − 1)/2)（对应 d = R − 1，此处 α 降为 0）。设 2 < R < 3。

**引理 2.** f_R 在 [β₀, β₁) 上严格递减、严格凹；在 (0, β₀) 上递增（该区间只在 R < √5 时非空），且 f_R ≤ A(R)；在 [β₁, π) 上 f_R ≡ 0。

*证明.* 由 α = 2 arccos x、β = 2u 得
α′(β) = −x′/√(1 − x²)，α″(β) = −[x″(1 − x²) + x·x′²] / (2(1 − x²)^{3/2})。
x′ = sin u·(a sec²u − b)，所以 x′ ≥ 0 ⟺ cos²u ≤ a/b = (R² − 1)/4 ⟺ β ≥ β₀。
x″ = a sec u·tan²u + cos u·(a sec⁴u − b)。当 a sec²u ≥ b（即 β ≥ β₀）时 a sec⁴u ≥ a sec²u ≥ b，所以 x″ > 0。在 (β₀, β₁) 上 0 < x < 1，x′ > 0，于是 α′ < 0、α″ < 0。∎

**用户原陈述的修正**："α(β) 单调减且凹"只在 [β₀, β₁) 上成立，且只用 Jensen 不能直接得到结论。有三处边界需要补：
1. k = 6（R = 2 < √5）时 β₀ = π/3 = m 恰好落在拐点，β < β₀ 时 f 反而递增；
2. 与内圆不相交的圆（d ≥ 2）满足 β = 0，但 α 最大可达 A(R) > f_R(0⁺)：β = 0 处对应的 α 不唯一，函数 β ↦ α 在 0 处"跳高"；
3. β ≥ β₁ 时 α ≡ 0，凹性断裂。

所以下面用**切线（支撑线）形式**代替 Jensen。它等价于 Jensen 的证明，但能把以上边界点逐个检查。

## 3. 对称性定理

**假设 H_k.** D(0, R) 被 D(0, 1) 与 k 个圆心 ≠ O 的单位圆盘覆盖。
由于环带 1 < |x| ≤ R 只能被这 k 个圆覆盖，取闭包可知这 k 个圆同时覆盖 Γ_1 与 Γ_R。由引理 1，覆盖圆周需要 Σβ_i ≥ 2π 且 Σα_i ≥ 2π。

**定理.** 设 k ∈ {6, 7, 8, 9}，R* = 1 + 2cos(2π/k)，m = 2π/k。在 H_k 下 R ≤ R*；当 R = R* 时，外圈必为正则环：k 个圆心都在距 O 为 2cos(π/k) 处，等角分布。对应 n = k + 1 = 7, 8, 9, 10，R* = 2, 2.2469796…, 1+√2, 2.5320888…，与已证最优值一致。

*证明.* 令 R = R*，L(β) = m + s(β − m) 为 f_R 在 m 处的切线，s = f_R′(m)。证书核对了以下各项：
(E0) f_R(m) = m（精确），(E1) s = (1 − 2C)/(1 + 2C) ≤ 0，其中 C = cos(2π/k)，(E2) β₀ ≤ m < β₁，(E3) L(0) ≥ A(R)，(E4) L(π) ≥ 0。

*断言：* 对每个圆心 ≠ O 的圆有 α ≤ L(β)，等号当且仅当 β = m。
- d ≥ 2（β = 0）：α ≤ A(R) ≤ L(0)（E3）。k ≥ 7 时 E3 严格成立；k = 6 时等号要求 d = √(R² − 1) = √3 < 2，与 d ≥ 2 矛盾，所以也取不到等号。
- β ∈ [β₀, β₁)：f 严格凹，L 是它在 m ∈ [β₀, β₁) 处的切线（E2），所以 f ≤ L，等号仅在 β = m。
- β ∈ (0, β₀)：f(β) < f(β₀) ≤ L(β₀) ≤ L(β)（s ≤ 0）。
- β ∈ [β₁, π)：α = 0 ≤ L(π) ≤ L(β)（E4）。k = 6..9 时 L(π) > 0，不等式严格。

*求和：* Σα_i ≤ Σ L(β_i) = km + s(Σβ_i − km) = 2π + s(Σβ_i − 2π) ≤ 2π（s ≤ 0，Σβ_i ≥ 2π）。
覆盖要求 Σα_i ≥ 2π，所以每一步都取等号。由断言，所有 β_i = m，于是 d_i = 2cos(π/k)，α_i = m。此时 k 段长 m 的闭弧覆盖 Γ_R 且总长恰为 2π，只能首尾相接，所以圆心等角分布。
*R > R* 的情形：* 这样的覆盖也覆盖 D(0, R*)，由上一步它必为上述正则环。但 ∂/∂R[(R² + d² − 1)/(2Rd)] = (R² − d² + 1)/(2R²d) > 0（d < 2 < R），所以 ω(R, 2cos(π/k)) 关于 R 严格递减，kω(R, ·) < 2π，Γ_R 覆盖不了。因此 R ≤ R*。∎

正则环确实覆盖 D(0, R*)：`ExactCoverQ[RingConfig[k], RingRadius[k]]` 对 k = 6..9 返回 True，对 R* + 10⁻³⁰ 返回 False（E5，精确判定）。

## 4. 适用范围与边界

- **方法在 k = 10 失效**：L(0) − A(R*) = −0.0072 < 0，即圆心在内圆之外（d ≥ 2）的圆可能比正则环更"划算"；k ≥ 11 时 L(π) 也变为负数。这与 n = 11 的记录 2.631 > 1 + 2cos(π/5) = 2.618 一致：n = 11 的最优结构已不是"中心圆 + 正则环"。
- 本定理**不**证明 n = 8, 9, 10 的最优性。缺的是去掉 H_k，也就是证明最优覆盖里一定有一个圆盘恰好覆盖 D(0, 1)。这是 Fejes Tóth 证明的另一半，本仓库尚未处理。
- 副产品（L3）：n = 8, 9, 10 的已证最优值精确等于 1 + 2cos(2π/k)，k = n − 1，并由精确构型 `RingConfig[k]` + `ExactCoverQ` 验证。
