## 0. 前提、命题

(i) 等价于 a, b ≥ R − 1 且 a + b ≤ 2（两段 [a−1,a+1]、[−b−1,−b+1] 覆盖 [−R,R]）。
引理 H1 证明了 (ii) 中“右边界弧只由两圆负责”的部分；“左侧圆不参与覆盖右侧的 V 点”仍属前提。

## 1. 记号（右半 x ≥ 0）

- α := arcsin(1/R)：单位圆盘与 ∂C_n 交弧角 ≤ 2α，等号 ⟺ 弦长 2。
- T1 = ∂C1 ∩ ∂C_n（x>0），y₁ = (R²+a²−1)/(2a)；T2 = ∂C2 ∩ ∂C_n（x>0），y₂ = −(R²+b²−1)/(2b)。
- V = ∂C1 ∩ ∂C2（x ≥ 0）= (√(1−s²), (a−b)/2)，s = (a+b)/2。
- A_R := ∂C_n 上从 T1 顺时针到 T2 的弧（= ∂C_n ∩ {x≥0} ∖ int(C1 ∪ C2)）。A_L 为其镜像。
- X(w) := T1 绕原点顺时针转 2α − w，w ∈ [0, 2α]；X0 := X(0)，|T1 X0| = 2。
- U_R := (C_n ∩ {x ≥ 0}) ∖ (C1 ∪ C2)。闭性：U_R 的闭包含 A_R 与 V（V 处两圆相切或相交，其右侧邻域内有 U_R 的点；且 |V| < R，证书 10a F2）。
- 容许域 Dom：R ∈ [R_lo, R_hi]，R_lo = 1.798867827575（< R₆，差 2.6e−12），R_hi = R_lo + 10⁻³；a, b ≥ R−1，a+b ≤ 2。

## 2. 归约引理

**单调性.** (H0) 下覆盖 D(0,R) 的同一组圆也满足 (H0) 并覆盖 D(0,R′)，R′ < R。故只需处理 R ∈ [R_lo, R_hi]，再由 R_hi 处不可覆盖推出 R > R_hi 不可覆盖。

**引理 H1（两侧各恰两圆）.** 记 2θ₁, 2θ₂ 为 C1, C2 在 ∂C_n 上的交弧角（θᵢ ≤ α）。
(a) 没有一个单位圆盘同时与 A_R、A_L 相交；(b) 与 A_R 相交的圆恰两个（记 C3, C4），A_L 同理。
*证明.* (a) 单位圆盘与 ∂C_n 的交是一段连通弧（≤ 2α < π）。若它同时碰 A_R 和 A_L，则必整个包含 C1 弧或 C2 弧，于是四段弧（C3–C6）的长度和 ≥ |A_R ∪ A_L ∪ C1弧| = 2π − 2θ₂ ≥ 2π − 2α。但长度和 ≤ 8α，而 10α < 2π（R_lo > 1/sin(π/5)，证书 10a F4），矛盾。
(b) |T1T2| > 2（10a F1）⟹ 没有单位圆盘同时含 T1, T2 ⟹ A_R 至少要两个圆；A_L 同理；共 4 个圆且由 (a) 两组不相交 ⟹ 各恰 2 个。【人工 + 10a】

**引理 H2（化为三点问题）.** 设 T1 ∈ C3，T2 ∈ C4（由 10a F1 二者不同圆）。由 (H0)(ii) V ∈ C3 ∪ C4。
- 若 V ∈ C3：作反射 y ↦ −y（交换 a ↔ b、C1 ↔ C2、T1 ↔ T2，容许域不变），化为下一种情形。
- 若 V ∈ C4：C3 ∩ ∂C_n 是含 T1 的连通弧（≤ 2α），而 A_R 角长 ≤ π，两弧长度和 < 2π ⟹ C3 ∩ A_R 是 A_R 的初始段 [T1, P]。由 10a F1，T2 ∉ C3，故 P ≠ T2，且 P 之后的 A_R 点都在 C4 中，C4 闭 ⟹ P ∈ C4。又 P 到 T1 的角距 ≤ 2α ⟹ P = X(w)，w ∈ [0, 2α]。

于是 **C4 是包含 V, T2, X(w) 三点的单位圆盘**（某个 w ∈ [0, 2α]）。【人工】

## 3. 三点不可容纳（引理 H3）与阈值 R₆

令 c₂(R,a,b,w) := 外接圆半径²(V, T2, X(w))，G(R,a,b) := c₂(R,a,b,0) − 1，
局部窗 N := [a~ − ρ, a~ + ρ] × [b~ − ρ, b~ + ρ] × [0, w₁]，ρ = 1/40，w₁ = 1/20，(a~, b~) 为 (a₆, b₆) 的 16 位有理近似。

- **H3-全局（证书 10d，L3）**：对 Dom 中所有 (R,a,b) 与 w ∈ [0, 2α(R)]，若 (a,b,w) ∉ N，则没有单位闭圆盘含 V, T2, X(w)。
  方法：区间 B&B（机器 Interval，向外舍入），三点可容纳判据同 09lib（两两距离 ≤ 2 且某透镜顶点距第三点 ≤ 1）。26 882 113 盒，8 837 s。
- **H3-局部（证书 10c，L3）**：在 [R_lo,R_hi] × N 上 (L1) 三角形 V,T2,X(w) 锐角；(L2) ∂c₂/∂w > 0；(L3) ∂G/∂R > 0；
  (L4) 在核心小盒 N_core（(a~,b~) 周围半径 r_c = ρ/32 = 1/1280，R ∈ [R_lo,R_hi]）上 G 关于 (a,b) 的 Hessian 正定；
  (L5) G(R_lo,a,b) > 0 于 N_ab ∖ N_core（区间中值形式 G(m)+∇G(盒)·(盒−m)，4 019 盒）。由 (L3)(L5)：R ≥ R_lo 时 G(R,·,·) 在 N_ab 上的非正值只能出现在核心，而核心上 G 严格凸。
  （直接在整个 N_ab 上证 Hessian 正定因区间依赖需 ~10⁵ 个 1e−4 宽的盒，上一轮因此超时；核心 + L5 的拆分秒级完成。）
  锐角三角形能被单位圆盘容纳 ⟺ 外接圆半径 ≤ 1，所以在 N 内：可容纳 ⟹ c₂(w) ≤ 1 ⟹（L2）G(R,a,b) ≤ c₂(w) − 1 ≤ 0，且等号要求 w = 0。
- **阈值（证书 10b，L3）**：m(R) := min_{(a,b)∈N_ab} G(R,a,b) 连续，且由 (L3) 严格递增。(B1) G(R_lo, a~, b~) ∈ [−1.034e−11, −1.020e−11] < 0 ⟹ m(R_lo) < 0；(B2) G(R_hi,·,·) > 0 于 N_ab（147 499 盒）⟹ m(R_hi) > 0。
  **定义 R₆ := m 在 (R_lo, R_hi) 中唯一零点。** G(R₆,·,·) 的极小点落在核心（L3+L5），核心上严格凸（L4）⟹ 极小点 (a₆, b₆) 唯一。
  (B3, 证据) wp 80 牛顿法解 G = G_a = G_b = 0，残差 < 10⁻⁷⁶，(a₆,b₆) 距 (a~,b~) < r_c/10（核心内点）。

## 3'. 弧长表述与去掉 w 的三维版本（证书 10e）

**用户表述**（上半 y ≥ 0，C1 = D((−p,0),1)，C2 = D((q,0),1)，Q1/Q2 = ∂C1/∂C2 ∩ ∂C_n，P12 = ∂C1 ∩ ∂C2，C3 ∋ Q1, P12）：
F(r,p,q) := θ1 + θ2 + 2β3 + 2α − π，其中 2β3 是“过 Q1, P12 的第二个单位圆”（第一个是 ∂C1）在 ∂C_n 上自 Q1 起的新弧角。
F ≥ 0 ⟺ C3 的新弧能到达 X（距 Q2 角距 2α 的点）⟺ Q1, P12, X 可被单位圆盘容纳（锐角情形）。
绕原点旋转 90° 后与本文记号对应：Q1 ↔ T2，P12 ↔ V，Q2 ↔ T1，p ↔ b，q ↔ a，X ↔ X0，“F < 0” ↔ “V, T2, X0 不可容纳”。
数值（`experiments/2026-10-11-n6-arc/arc.wls`，wp50，L2 单实现）：F = ∇F = 0 的根与 R₆ 差 4.7e−45，(p,q) = (b₆,a₆)。

**引理 H2'（去掉 w）【人工】.** 在 H2 的情形 V ∈ C4 下，C4 ⊇ {V, T2, X0}。
*证明.* 由 H2，C3 ∩ A_R = [T1, P]，P 到 T1 的角距 ≤ 2α，且 A_R 上 P 之后的点（含 T2）都在 C4 中。由 10a F1（|T1T2| > 2），A_R 的角长 > 2α，所以 X0（距 T1 角距恰为 2α）位于 P 与 T2 之间的子弧上，因而 X0 ∈ C4。∎

于是 H3 只需在 w = 0 处成立：

- 再加 10b（B1,B2）与 10c（L3,L4,L5），§4 的拼装照搬，不再需要 10d 与 10c 的 (L1),(L2)。10d 保留为冗余交叉证书。

## 4. 拼装（定理 10 的证明）

1. R ∈ (R₆, R_hi]：由 H2，C4 含 V, T2, X(w)。H3-全局 ⟹ (a,b,w) ∈ N；H3-局部 ⟹ G(R,a,b) ≤ 0；但 G(R,a,b) ≥ m(R) > m(R₆) = 0，矛盾。R > R_hi 由单调性。⟹ 结论 1。
2. R = R₆：同上得 G(R₆,a,b) ≤ 0 = m(R₆) ⟹ (a,b) = (a₆,b₆) 且 w = 0、c₂ = 1。
   - C4：含锐角三角形 V,T2,X0 且外接圆半径恰 1 的单位圆盘唯一，即外接圆盘。
   - C3：含 T1, X0 且 |T1X0| = 2 ⟹ C3 = D(mid(T1,X0), 1)。
   - 左半：对 x ↦ −x 镜像后是同一个半圆问题，且 a、b 与右半共用。右半给出 (a,b) ∈ {(a₆,b₆), (b₆,a₆)}（后者来自 H2 的反射情形），左半同理；因 a₆ ≠ b₆，两侧必属同一情形 ⟹ C5, C6 是 C3, C4 的镜像。
   ⟹ 构型在合同意义下唯一，关于 y 轴镜像对称；a₆ ≠ b₆ 说明没有关于 x 轴的对称，也没有旋转对称（C1、C2 与原点距离不同）。⟹ 结论 2。
3. 存在性：`experiments/2026-10-10-n6-proof/exist.wls` 按上式构造六圆，`make verify` 通过（L2）。⟹ 结论 3（L2）。
