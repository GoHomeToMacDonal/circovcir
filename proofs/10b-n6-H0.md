## 0. 记号与约化

C = D(0,R)，单位闭圆盘 O₁,…,O₆ 覆盖 C。α = arcsin(1/R)；圆心距原点 d 的单位圆盘与 ∂C 的交是连通弧，半角
θ(d) = arccos((R²+d²−1)/(2Rd))（不相交时为 0），θ 在 [R−1, d*] 上递增、d* = √(R²−1) 处取最大值 α，故对 d ≤ d_max 有 θ(d) ≤ θ(min(d_max, d*))。

**半径约化.** 若 R > R₆ 时有覆盖，则同一组圆覆盖 D(0,R′)，R′ = min(R, R_lo+10⁻¹⁰) ∈ (R₆, R_lo+10⁻¹⁰]（R₆ − R_lo ≈ 2.6·10⁻¹²）。所以只需处理 R ∈ I := [R_lo, R_lo+10⁻¹⁰]，它含 R₆，且 ⊂ proofs/10 的 [R_lo, R_hi]。证书 10f/10g 在每个盒上都用整个区间 I 计算。

**步骤 0（每个圆都碰到边界）.** 5 段弧总长 ≤ 10α < 2π（10a F4），所以 6 个圆都与 ∂C 相交，|cₖ| ≥ R−1。【人工】

**步骤 1（用户第 1 步）.** 设 O₁ ∋ 0，则 R−1 ≤ |c₁| ≤ 1。旋转使 c₁ = (0,a)，a ∈ [R−1,1]。O₁ 覆盖 y 轴段 [a−1, R]；剩余段 S = [−R, a−1]（在 y 轴上）。记 q = (0,a−1)，b = (0,−R)。

**步骤 2（分情况，用户第 2/3 步）.** 情形 2：某个圆 P 同时含 q 与 b（等价于 P ⊇ S，P ≠ O₁）。情形 3：没有圆同时含 q 与 b，即 S 至少要两个圆。
两种情形下都取 P 为 ≠ O₁ 且含 q 的圆（q 正下方的点在 C 内、不在 O₁ 中；圆有限且闭）。关于 y 轴镜像，可设 P 的圆心 (x,y) 满足 x ≥ 0。

弧的记号：I₁ = [π/2−θ₁, π/2+θ₁]，I_P = [φ_P−θ_P, φ_P+θ_P]，φ_P = arcsin(y/|c_P|) ∈ [−π/2, π/2]；
左缺口 g_A = 3π/2 + φ_P − θ_P − θ₁，右缺口 g_B = π/2 − φ_P − θ_P − θ₁（分别为 ∂C ∖ (I₁ ∪ I_P) 的左、右两段之长）。

## 1. 情形 3 不可能（证书 10f，L3）

**见证点.** 若 w ∈ C，且 w 附近有不属于 O₁ ∪ P 的点，则另有一圆 Q ≠ O₁, P 含 w，于是 |c_Q| ≤ 1+|w|，Q 的弧半角 ≤ θ_Q := θ(min(1+|w|, d*))。用两类 w：
- w₁ = (0, y − √(1−x²))：P 在 y 轴上弦的下端。P ∋ q 且 P ∌ b ⟹ −R < w₁ ≤ a−1，其正下方的点不在 P、也不在 O₁。（总成立）
- w₂, w₃：∂O₁ 与 ∂P 的两个交点，要求 |w| < R（交点处总有不在两圆中的点）。

**弧覆盖判据.** 其余三圆的弧 ≤ 2α。缺口集 G₀ = ∂C ∖ (I₁ ∪ I_P) 要被长度为 {2α, 2α, 2α, 2θ_Q} 的四段弧覆盖。若 g_A, g_B > 0（两段缺口），可行当且仅当
(分组) 四段弧可分成两组，长度和分别 ≥ g_A、≥ g_B；或 (搭桥) 总长 ≥ 2π − max(|I₁|, |I_P|)（某段弧跨过 I₁ 或 I_P，则所有弧的并要覆盖一段连通的长弧）。
否则（只有一段缺口）必须总长 ≥ g_A + g_B。【人工：一维覆盖的组合论证】

**证书 10f.** 对 (a,x,y) ∈ [R_lo−1,1] × [0,1] × [−1.21,1] 中每个与情形 3 区域 {|c_P−q| ≤ 1, |c_P−b| > 1} 相交的盒，至少一个有效见证使上述覆盖不可能（区间 B&B，机器 Interval 向外舍入，220 909 盒，71 s）。
负对照：R = 1.79528 时的三重对称覆盖（三个圆过原点；即宽搜得到的局部最优 R ≈ 1.795281，`experiments/2026-10-02-bezdek-fejestoth-verify/out/n6-wide-s200.json`，L1）不被排除。
⟹ R ∈ I 时情形 3 不出现。

浮点探索（L1）：判据的最小裕量约 4.5·10⁻³ rad（每段弧需再长这么多才可行），在 a ≈ 0.963、c_P ≈ (0.893, −0.486)；只看弧长和的旧判据（Σ 损失 ≤ 12α − 2π）裕量为负，不够用——必须用缺口的分段结构。

## 2. 情形 2 化为 proofs/10（证书 10g，L3）

设 P ∋ q, b，x ≥ 0。令 C₂* = D((0,y),1)，b′ = −y。

**(a) 帽子引理（用户第 2 步的对称化）.** 对 p_x ≤ 0：|p − c_P|² = |p − (0,y)|² − 2p_x x + x² ≥ |p − (0,y)|²，所以 P ∩ {x ≤ 0} ⊆ C₂*。特别地 C₂* ∩ y 轴 ⊇ P ∩ y 轴 ⊇ S，于是 b′ ≥ R−1、a + b′ ≤ 2，即 (R,a,b′) 属于 proofs/10 的容许域 Dom。【人工】

**(b) 两侧各恰两圆.** 弧长预算 2θ₁ + 2θ_P + 8α ≥ 2π（否则无覆盖）。10g 门 G2：在预算可行的区域上 g_A > 2α 且 g_B > 2α（I₁、I_P 不相交）。
若另外四圆中有一段弧同时碰到左右缺口，它包含 I₁ 或 I_P，则四弧总长 ≥ 2π − 2α，即 10α ≥ 2π，与 10a F4 矛盾。因此左缺口 A_L 恰由两圆 O₃, O₄ 的弧覆盖，右缺口 A_R 恰由 O₅, O₆ 覆盖，两组互不相交。【人工 + 10g G2 + 10a F4】

**(c) 引理 V（关闭 proofs/10 中"左侧圆不参与覆盖 V"的前提）.** 令 V* = (−√(1−s²), (a−b′)/2)，s = (a+b′)/2，为 ∂O₁ 与 ∂C₂* 的左交点。
cl(A_R) 被 I₅, I₆ 覆盖且 |A_R| > 2α ⟹ 两段交集一段含 A_R 的起点 T2P（I_P 的逆时针端）、一段含终点 T1，且各覆盖长 ≥ |A_R| − 2α 的端段。端段的另一端分别是 X0 = T1 顺时针转 2α，与 Y = T2P 逆时针转 2α。
10g 门 V2：{V*, T2P, X0} 与 {V*, T1, Y} 都不能被一个单位闭圆盘容纳（三点判据同 10lib-n6；2 889 915 盒，1 506 s）。⟹ O₅, O₆ 都不含 V*。
V* 左侧附近有不在 O₁ ∪ C₂* 中的点，由 (a) 它们也不在 P 中，又 |V*| < R（10a F2）；闭性 ⟹ V* ∈ O₃ ∪ O₄。

**(d) 套用 proofs/10.** 对 x ↦ −x 镜像后：C1 = O₁、C2 = C₂* 圆心在 y 轴上并覆盖直径；proofs/10 的右边界弧（这里是左侧 ∂C ∖ (O₁ ∪ C₂*) 那一段 A_L*）满足 A_L* ⊆ A_L ⊆ I₃ ∪ I₄，且其他圆的弧不碰 A_L；V* ∈ O₃ ∪ O₄。这正是 proofs/10 引理 H2 用到的全部前提（(H0)(ii) 只在这一步被使用）。于是 H2 + H3（10b–10d 或 10e）给出 R ≤ R₆。

## 3. R = R₆ 时的唯一性

- 情形 3 不出现（10f，R₆ ∈ I）。
- 情形 2：proofs/10 §4.2 给出 (a,b′) = (a₆,b₆) 或经 y ↦ −y 反射的 (b₆,a₆)。后者意味着 a = b₆ > 1，与 O₁ ∋ 0 矛盾。所以 (a,b′) = (a₆,b₆)，w = 0，O₄ = 外接圆盘(V*, T2*′, X0′)，O₃ = D(mid(T1′,X0′),1)（镜像记号）。此时 O₄ 的弧恰为 [X0′, T2*′]（两端都在 ∂O₄ 上）。
- x = 0：若 x > 0，取 ∂C 上紧挨 T2*′、位于 C₂* 弧一侧的点 p。p 不在 O₃, O₄（弧端点），不在 O₁；由 (a) 的严格形式 |p − c_P|² = |p − (0,y)|² + 2|p_x|x + x² 且 |p−(0,y)| → 1、p_x → T2*′_x < 0，p 也不在 P；故 p ∈ A_L，只能由 O₃ ∪ O₄ 覆盖，矛盾。所以 P = C₂*。
- x = 0 时左右两侧地位相同，对右半做同样论证，O₅, O₆ 是 O₃, O₄ 的镜像。⟹ 构型唯一，关于 y 轴镜像对称（proofs/10 定理 10 第 2 条，不再依赖 (H0)）。【人工】
