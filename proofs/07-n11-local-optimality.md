# n=11：Melissen 构型是严格局部极大（L3，区间证书）

证书：`proofs/certificates/07-n11-local-opt.wls`（自包含，exit 0，约 15 s）。数据来源：`experiments/2026-10-08-n11-kkt/`。

## 定理

设 c* 为 Melissen n=11 构型（竖直镜像对称：轴上 S0,S1,S2 + 4 对镜像圆），R* ∈ [2.6316907726198082055215011595056961051671168478238, …39]（区间宽 < 1e-49）。则：

1. 11 个单位圆以 c* 为心**恰好**覆盖 D(0, R*)（ρ(c*, R*) = 1）。
2. 存在 c* 的邻域 N，使得任意 c ∈ N，若其单位圆覆盖 D(0, R)，则 R ≤ R*；取等号当且仅当 c 是 c* 的旋转。

即 c* 是可覆盖半径在 (R²)¹¹ 中模旋转的**严格局部极大**。**不是**全局最优性陈述——n=11 的最优性仍开放。

## 表述

z = (c₁,…,c₁₁, R) ∈ ℝ²³。在 18 个活跃紧点上取 h_t(z) ≤ 0，h_t > 0 表示该处开洞：

- 内部点（9 个，三圆 i,j,k 的外心）：h = circumradius²(cᵢ,cⱼ,c_k) − 1；
- 边界点（9 个，圆 i,j）：h = R² − |y_ij|²，y_ij 为两单位圆的外交点。

问题 (P)：max R s.t. h(z) ≤ 0，规范条件 z₅ = 0（S2 的 x 坐标，用来消去旋转）。

## 证书步骤

所有区间都是 Mathematica `Interval`（100 位 bigfloat，向外舍入）；正定判定用精确有理数。

| 步骤 | 内容 | 结果 |
|---|---|---|
| K1 | 对称 22×22 KKT 系统 F(u)=0（10 条约束 + 12 条 ∂L/∂(q,R)，u=(q,R,λ)）的 Krawczyk 检验：盒半径 1e-45，K(X) ⊂ int X | 盒内存在唯一零点 u*；K 的宽度 / X 的宽度 ≈ 2e-42 |
| K2 | λ 的区间下界 | 18 个 λ 全 > 0（最小 0.01205） |
| K3 | Finsler 引理：M = −(H_L − ρBᵀB)，B = [∇h ; e₅]，ρ=1，在整个盒上取 M 的中点有理矩阵减去 dF·I（dF=1e-30 ≥ 23·最大宽度），精确判定正定（`PositiveDefiniteMatrixQ` + Sylvester 23 个主子式） | 正定；λ_min(mid) = 0.0447 |
| K4 | 局部等价的间隙：每个活跃紧点与其余 8 个圆心的距离² − 1 ≥ 1.04；内部点在 D 内；边界点在外向分支上 | 全部成立 |
| K5 | 在 z* 处逐一检查全部 286 个有限候选点（`docs/methods.md`）：18 个活跃点（f=1）；236 个 f<1 已证；26 个在 K 外；5 个由对称性恰为 J；1 个三点精确共线 | 全部覆盖到，ρ(c*,R*) = 1 |

## 推理链

- **K1 + 对称临界性**：L 在镜像 σ 下不变（λ 与镜像约束绑定），故 ∇L(z*) 落在 σ 的不动子空间；对称系统令它在该子空间上为零 ⇒ 全空间 ∇L(z*) = 0。镜像孪生约束有 h_{t'}(σz) = h_t(z) ⇒ 18 个 h 全为 0。所以 z* 是 (P) 的 KKT 点，规范乘子为 0。
- **K2 + K3 ⇒ 二阶充分条件**：严格互补时临界锥 = null(∇h) ∩ {d₅=0}。Finsler 引理：H_L − ρBᵀB 负定 ⇒ H_L 在 null(B) 上负定。由 Nocedal–Wright《Numerical Optimization》二阶充分条件定理（2nd ed. Thm 12.6，编号待核实；极大化形式；不需要 LICQ），z* 是 (P) 的严格局部极大。
- **K4 ⇒ 局部等价引理**：在 z* 附近，若 c 覆盖 D(0,R)，则所有 h_t ≤ 0。理由：活跃点 x_t(z) 连续，其余圆心离它 > 1，所以 x_t 只能由它的生成圆覆盖。内部点：外接半径 ≤ 1。边界点：沿中垂线外向时 |·| 单调，故中垂线与圆周的交点到 cᵢ 的距离 ≤ 1 ⇔ |y_ij| ≥ R。
- **规范**：S2 ≠ 0，所以任何邻近构型可以小角度旋转到 z₅ = 0；覆盖与 R 都不变。若邻近构型覆盖 R > R*，则也覆盖 R' ∈ (R*, R]，取 R' 足够接近 R*，与 (P) 的严格局部极大矛盾。
- **K5 + 有限候选集定理 ⇒ 第 1 条**。

## 依赖与限制

- 依赖：有限候选集定理（`docs/methods.md`）；NLP 二阶充分条件定理（教科书）；Mathematica `Interval` 的向外舍入（与证书 05 相同）。
- 活跃集是数值上识别出来的（`experiments/2026-10-08-n11-kkt/run.wls`）；证书只验证这个活跃集，并通过 K5 证明在 z* 处没有遗漏的紧点。
- "2 个内部自由度"（`rigidity_check.wls`）指的是**接触等式族**；在不等式表述下 R 沿全部 4 个非平凡方向都严格下降——这是"应力刚性"，与本定理不矛盾。
