## 0. 命题

令 R₅ 为 625t⁸−800t⁷+22t⁶−1776t⁵+1665t⁴+1360t³−3480t²+2112t+1296 在 1.641 附近的实根
（R₅ = 1.64100446360361570065…，见 `proofs/04`）。

**定理.** 5 个单位闭圆盘能覆盖 D(0,R) ⟺ R ≤ R₅。

- ⟸（存在性）：用约化问题的精确解 (R₅, d*) 构造代数坐标构型，`ExactCoverQ`（引理 E）。
- ⟹（最优性）：下文 §1–§8。

## 1. 归约与记号

**单调性.** 若 5 圆覆盖 D(0,R)，则覆盖一切 D(0,R′)，R′<R。故只需证：对每个 R ∈ (R₅, R₅+δ]（δ = 1/1000）不存在覆盖。

设 D₁,…,D₅ 覆盖 C_n = D(0,R)。原点被某圆覆盖，记为 C1 = D₁，旋转使其圆心为 (0,d)，0 ≤ d ≤ 1。

- α := arcsin(1/R)：单位圆盘与 ∂C_n 的交弧的最大**半**角（交弧角 ≤ 2α，等号 ⟺ 弦长 2）。
- 若 C1 与 ∂C_n 相交，角点 T_R, T_L = ∂C_n ∩ ∂C1，y_T = (R²+d²−1)/(2d)。
- ψ：∂C_n 上从底点 (0,−R) 起算的带号极角，A(ψ) = R(sin ψ, −cos ψ)；ψ_T := ψ(T_R) = π − arccos(y_T/R)。
- φ：∂C1 上从 C1 底点 (0,d−1) 起算的带号角，B(φ) = (sin φ, d − cos φ)；φ_T := φ(T_R)。
- **A** := ∂C_n ∖ int C1 = {A(ψ) : |ψ| ≤ ψ_T}；**B** := ∂C1 ∩ C_n = {B(φ) : |φ| ≤ φ_T}。
- 闭性论证：A、B 上每点都是 C_n ∖ C1 中点的极限，故 A ∪ B ⊆ D₂ ∪ … ∪ D₅。
- 每个 D_i ∩ A 是 A 上一段弧 I_i（角长 ≤ 2α），D_i ∩ B 是 B 上一段弧 J_i。

## 2. 引理 1（C1 必触及 ∂C_n）

若 d + 1 < R，则 D₂…D₅ 覆盖整圆 ∂C_n，故 8α ≥ 2π，即 R ≤ √2 < R₅，矛盾。【人工 + 精确比较 √2 < R₅】

## 3. 引理 2（计数与排序）

|A| = 2ψ_T ≤ Σ|I_i| ≤ 8α。令 m := 2ψ_T − 6α。需证 m > 0 在全部容许 (R,d) 上成立
⟹ 四段弧都不可去掉；按左端点排序 l₂ > l₃ > l₄ > l₅（右端点同序 r₂ > … > r₅），相邻重叠。
由此（取 P := A(l₃) ∈ I₃ ∩ I₄）：

- (2a) r₃ ≥ l₂ ≥ ψ_T − 2α；(2b) l₄ ≤ r₅ ≤ −ψ_T + 2α；
- (2c) ψ_P := l₃ ∈ [ψ_T − 4α, 4α − ψ_T]（区间很窄，最优处 ±0.067）；
- (2d) 链式不等式：r₃ ≤ l₃ + 2α = ψ_P + 2α；l₄ ≥ r₄ − 2α ≥ ψ_P − 2α；D₂ ∋ T_R，D₅ ∋ T_L。
- 容许 d 的范围：2ψ_T(R,d) ≤ 8α ⟹ d ≥ d_min(R)（R=R₅ 时 d_min ≈ 0.8457）；且 d ≤ 1。

**证明要点.** 若某一段 I_i 可以去掉，则剩下三段覆盖 A，有 2ψ_T ≤ 6α，即 m ≤ 0，矛盾。
因此四段互不包含，左端点与右端点同序；A 连通，故相邻两段重叠（r_{k+1} ≥ l_k）。
P = A(l₃) 落在 I₄ 中，因为 l₄ < l₃ ≤ r₄。P 右侧且在 I₃ 之外的点（即大于 r₃ 的点）只能被 I₂ 覆盖，所以 l₂ ≤ r₃，
又 I₂ ∩ A ⊆ [ψ_T − 2α, ψ_T]，得 (2a)。左侧同理得 (2b)。(2c) 由 (2a)(2b) 与各段长 ≤ 2α 推出。

## 4. 到达函数（引理 3）

- **E(ψ, φ)** := 所有同时包含 A(ψ) 与 B(φ) 的单位圆盘中，A 弧右端点的最大值（取 −∞ 若 |A(ψ)B(φ)| > 2）。
- **E₂(t)** := 所有同时包含 T_R 与 B(t) 的单位圆盘中，A 弧左端点的最小值（取 +∞ 若无此圆盘）。
- 镜像：包含 A(ψ)、B(φ) 的单位圆盘，其 A 弧左端 ≥ −E(−ψ, −φ)；包含 T_L、B(t) 的单位圆盘，其 A 弧右端 ≤ −E₂(−t)。

**引理 3（闭式）.** 在容许域内，E(ψ,φ) = 2ψ(c) − ψ，其中 c = c(A(ψ),B(φ)) 是过这两点的单位圆中位于有向线段 P→Q 右侧的那个圆心；
E₂ 有类似的透镜顶点公式。
依据：X 可达 ⟺ {P, Q, X} 的最小包围圆半径 ≤ 1 ⟺ X ∈ Lens(P,Q) ⊕ D(0,1)；在临界点 X 处，X − c 落在透镜于顶点 c 处的法锥内（区间验证）。
数值实现（不做结构假设）见 `reach.py`，它用最小包围圆判定加二分。

**引理 4（单调性）.** E 关于 ψ、φ 都不减；E₂ 关于 t 不增。（几何上直接：被包含的点向"有利方向"移动时，可行圆盘集合增大。需要区间核验或手证。）

## 5. 按 B 的覆盖方式分情形（引理 5）

J₃、J₄ 是 B 上的闭区间（可能为空）。

- **好情形 G**：存在 Q ∈ J₃、Q′ ∈ J₄，φ_Q ≤ φ_{Q′}。
  D₃ ∋ P, Q ⟹ c ≤ r₃ ≤ E(ψ_P, φ_Q) ≤ E(ψ_P, φ)；D₄ ∋ P, Q′ ⟹ c ≤ −l₄ ≤ E(−ψ_P, −φ_{Q′}) ≤ E(−ψ_P, −φ)，
  这里 φ ∈ [φ_Q, φ_{Q′}] 任取，c := ψ_T − 2α。
  ⟹ **min(E(ψ_P, φ), E(−ψ_P, −φ)) ≥ c**。
- **坏情形**：sup J₄ < inf J₃（约定 sup ∅ = −φ_T、inf ∅ = φ_T）。开空隙 𝒢 = (sup J₄, inf J₃) ⊆ J₂ ∪ J₅，且 𝒢 连通，于是：
  - (a) 𝒢 ⊆ J₂：记 t = sup J₄，有 B(t) ∈ D₂。由 l₂ ≤ r₃ ≤ ψ_P + 2α 得 E₂(t) ≤ ψ_P + 2α。
    若 J₄ ≠ ∅，还有 B(t) ∈ D₄ ⟹ E(−ψ_P, −t) ≥ c。若 J₄ = ∅，则 t = −φ_T，单凭 E₂(−φ_T) ≤ ψ_P + 2α 即可。
  - (b) 𝒢 ⊆ J₅：作镜像 (ψ_P, t) ↦ (−ψ_P, −inf J₃)，化为 (a)，因为 ψ_P 的范围关于 0 对称。
  - (c) J₂ ∩ J₅ ∩ 𝒢̄ ∋ B(t)：E₂(t) ≤ ψ_P + 2α 且 E₂(−t) ≤ 2α − ψ_P ⟹ **E₂(t) + E₂(−t) ≤ 4α**。

## 6. 需要的不等式（对 R ∈ (R₅, R₅+δ]、d ∈ [d_min, 1]，记 w := 4α − ψ_T）

- **(IG)** 对 |ψ| ≤ w、|φ| ≤ φ_T：min(E(ψ,φ), E(−ψ,−φ)) < c。
  分解：在 (0,0) 附近用偶凹性 E(x) + E(−x) ≤ 2E(0)（区间 Hessian）加 E(0,0) < c（即 L8：gap < 0）；远离 (0,0) 处直接用区间 B&B。
- **(Ia)** 对 |ψ| ≤ w、|t| ≤ φ_T：E₂(t) > ψ + 2α 或 E(−ψ,−t) < c；以及 E₂(−φ_T) > w + 2α。
- **(Ic)** 对 |t| ≤ φ_T：E₂(t) + E₂(−t) > 4α。

数值（L1，`reach.py`，R ∈ {R₅, R₅+10⁻³}，d 在 [0.85, 1] 上取 11 点网格）：

| 不等式 | 实测余量 |
|---|---|
| IG | R₅ 时 max ≈ −8e−6，在 d* 附近趋于 0，符合预期；R₅+10⁻³ 时 ≤ −3.5e−3 |
| Ia | ≤ −5.5e−3 |
| Ia（J₄=∅） | ≈ −1.04 |
| Ic | ≥ +1.1e−2（最紧处在 d = 1） |

**L8（约化不等式）.** gap(R,d) := 2α + 2ψ₃ − ψ_T < 0，其中 ψ₃ = arctan(√(4−(R+d−1)²)/(R+1−d))，E(0,0) = 2ψ₃。
gap(R₅, ·) 的最大值 0 在 d* 处取到（Gröbner 给出八次式，见 `reduced.wls`）；另需 ∂_R gap < 0。

## 6′. 用 fits 谓词重述（取代 L3、L4 的全局部分）

fits(P,Q,X) :⟺ 存在一个单位圆盘同时包含 P、Q、X
⟺ 三点两两距离都 ≤ 2，且三个两两透镜中至少有一个顶点到第三点的距离 ≤ 1。
（三个全等圆盘两两相交时，若交集非空，则交集边界上的顶点必是某个两两透镜的顶点；若交集恰为某个整透镜，则该透镜的两个顶点都在第三个盘内。）

单位圆盘与 ∂C_n 的交是一段角长 ≤ 2α < π 的弧，所以：
- E(ψ,φ) ≥ y ⟺ fits(A(ψ), B(φ), A(y))，其中 y ≥ ψ；
- E₂(t) ≤ y ⟺ fits(T_R, B(t), A(y))。

据此三类不等式改写为（ψ ∈ [−w, w]，c = ψ_T − 2α）：
- (IG′) 不存在 φ₁ ≤ φ₂ 使 fits(A(ψ),B(φ₁),A(c)) 与 fits(A(ψ),B(φ₂),A(−c)) 同时成立；
- (Ia′) 不存在 t 使 fits(T_R,B(t),A(ψ+2α)) 与 fits(A(ψ),B(t),A(−c)) 同时成立；另外 fits(T_R,T_L,A(ψ+2α)) 不成立；
- (Ic′) 不存在 t 使 fits(T_R,B(t),A(ψ+2α)) 与 fits(T_L,B(t),A(ψ−2α)) 同时成立。

验证方式：对 (R,d,ψ) 做三维区间 B&B，内层对 φ 做分格扫描。
IG′ 在最优点 (R₅,d*,0,0) 处取等，所以要挖掉一个小邻域 N，在 N 内用闭式 E、E 关于 φ 的单调性、偶凹性加 L8 证明。

## 7′. 拼装：每一步由哪道门关闭

设 R ∈ (R₅, 1.643]，5 个单位圆盘覆盖 D(0,R)。下面推出矛盾。

1. **C1 与 d 的范围。** 由 09a G2、G7：C1 与 ∂C_n 相交，有两个角点。由 09a G3、G5：d ∈ [0.845, 1]。
2. **A∩D_i、B∩D_i 都是一段弧**（补证）。若某个 D_i（i ≥ 2）同时含 T_R 和 T_L，则 D_i ∩ ∂C_n 是含这两点的一段连通弧，长度 ≤ 2α < 2ψ_T，只能经过顶部。于是它在 A 上的部分总长 ≤ 2α + 2ψ_T − 2π。另一方面，L2 要求每个 D_i 在 A 上的覆盖测度 ≥ m = 2ψ_T − 6α。两者相容需要 8α ≥ 2π，即 R ≤ √2，与 09a G2 矛盾。所以没有 D_i 同时含两个角点。由此 D_i ∩ A 与 D_i ∩ B 都连通：圆盘与圆的交是连通弧，再与端点为 T_R、T_L 的弧相交，只有含两个端点时才会断成两段。
3. **排序与 P.** 由 L2（§3，【人工】）和 09a G4（m > 0）：四段弧按左端点排序，P = A(ψ_P) 满足 (2a)–(2d)，且 |ψ_P| ≤ w(R,d) ≤ 0.09（09a G6）。
4. **分情形.** 按 §5（【人工】），出现 G、(a)、(b)、(c) 之一。
5. **好情形 G**（φ₁ ≤ φ₂，B(φ₁) ∈ D₃，B(φ₂) ∈ D₄）。
   - D₃ 含 P、B(φ₁)、A(c)：因为 ψ_P ≤ c ≤ r₃，且 D₃ 的 A 弧是 [l₃, r₃]。由 09e F1，φ₁ > −Φ₀。
   - D₄ 含 P、B(φ₂)、A(−c)：同理，由 09e F1，φ₂ < Φ₀。所以 φ₁、φ₂ ∈ (−Φ₀, Φ₀)。
   - 由 09d D4–D6：在窗口 W 内，fits(A(ψ),B(φ),A(y)) ⟺ y ≤ E(ψ,φ)（y ∈ [ψ, ψ+2α]）。又 c − ψ ≤ c + w = 2α，所以 E(ψ_P,φ₁) ≥ c，并由镜像得 E(−ψ_P,−φ₂) ≥ c。
   - 不妨设 ψ_P ≥ 0：镜像 (ψ,φ₁,φ₂) ↦ (−ψ,−φ₂,−φ₁) 保持 φ₁ ≤ φ₂。
   - 定义 φ₃。由 09d D1（E_φ > 0）、D2（E_ψ > 0）和 F1（E(ψ′,−Φ₀) < c），对每个 ψ′ ∈ [−ψ_P, ψ_P]，方程 E(ψ′,φ) = c 在 (−Φ₀, −φ₂] 内有唯一解 φ₃(ψ′)。φ₃ 光滑，且由 09d D3（φ₃″ = −Qn/E_φ³ > 0）是凸函数。
   - 推出矛盾：φ₃(ψ_P) ≤ φ₁，φ₃(−ψ_P) ≤ −φ₂，所以 2φ₃(0) ≤ φ₃(ψ_P) + φ₃(−ψ_P) ≤ φ₁ − φ₂ ≤ 0。于是 E(0,0) ≥ E(0, φ₃(0)) = c，即 gap(R,d) ≥ 0，与 09b（L8）矛盾。这里用到 E(0,0) = 2ψ₃：P、Q 都在 y 轴上，右侧圆心为 (a,h)。
6. **情形 (a).** 若 J₄ ≠ ∅，与 09e F2 矛盾；若 J₄ = ∅，与 F3 矛盾。
   情形 (b) 镜像为 (a)，ψ′ = −ψ_P ∈ [−w,w]：J₃ ≠ ∅ 对应 F2，J₃ = ∅ 对应 F3。
   这里用到：D₅ ∋ A(ψ_P − 2α)，因为 l₅ ≤ −ψ_T ≤ ψ_P − 2α ≤ l₄ ≤ r₅。
7. **情形 (c).** 与 09e F4 矛盾。
   这里用到：D₂ ∋ A(ψ_P+2α)，因为 l₂ ≤ r₃ ≤ ψ_P + 2α ≤ ψ_T；D₅ ∋ A(ψ_P−2α)，同上。

故 R ≤ R₅。结合存在性（09c），定理成立。∎

### 7″. 自审记录（2026-10-10，math）

逐条重查了【人工】步骤，结果如下：

- **L2.** 某段可去掉 ⟹ 2ψ_T ≤ 6α，与 m > 0 矛盾。因此四段互不包含，按左端点严格排序，右端点也严格同序（否则会出现包含）。
  (r₃, l₂) 内的点只能由 I₂ 覆盖，所以 l₂ ≤ r₃。I₂ 必须含 ψ_T（它的右端点最大），所以 l₂ ≥ ψ_T − 2α。

- **分情形.** "非好情形"⟺ J₃ 或 J₄ 为空，或 min J₃ > max J₄（两者都是闭区间）。约定 sup ∅ = −φ_T、inf ∅ = φ_T 后，空隙 𝒢 都是 B 上的开区间。
  (c) 的论证：𝒢 = (J₂∩𝒢) ∪ (J₅∩𝒢)，两部分都在 𝒢 中相对闭；𝒢 连通，所以若两部分都非空，它们必相交。

- **好情形用到的包含关系.** A(c) ∈ [l₃, r₃]：c ≥ 1.17 > w ≥ ψ_P = l₃，且 c ≤ r₃ 由 (2a) 给出。A(−c) ∈ [l₄, r₄]：l₄ ≤ −c 由 (2b) 给出，且 −c < −w ≤ ψ_P ≤ r₄。
- **区间算术的前提**：09d、09e 用的是机器精度 `Interval`。Wolfram 官方文档明确写明 "In operations on intervals that involve approximate numbers, the Wolfram Language always rounds lower limits down and upper limits up"（[Interval 文档](https://reference.wolfram.com/language/ref/Interval.html)）。所以这两份证书对内核的信任程度与其它证书相同。
  另一个需要说明的点：定义域端点（1641004/10⁶、1.643、0.845、±0.09、±0.15、2.5）在转成机器数时可能偏移约 1e−16。但实际要覆盖的范围距这些端点都留有余量，所以不受影响：
  - R 只需覆盖 (R₅, R₅+10⁻³]，而 R₅ − 1641004/10⁶ ≈ 4.6e−7，且 1.643 − (R₅+10⁻³) ≈ 1e−3；
  - d_min ≥ 0.8457，比下端点 0.845 多出约 7e−4；
  - w ≤ 0.0881 < 0.09；
  - φ_T < 2.5；
  - ±Φ₀ 在 09d 和 09e 中是同一个机器数，所以两份证书的窗口边界完全一致。
