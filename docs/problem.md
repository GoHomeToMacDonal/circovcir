# 问题定义

## 主问题

对正整数 n，定义

R_n = sup { R : 存在 c_1, …, c_n ∈ ℝ² 使 D(0,R) ⊆ ⋃ D(c_i, 1) }，

其中 D(p, ρ) 是以 p 为心、ρ 为半径的闭圆盘。等价的无量纲形式：r_n = 1/R_n 是 n 个等圆覆盖单位圆盘所需的最小公共半径。

对固定构型 c，定义覆盖半径（covering radius / 最远点距离）

ρ(c, R) = max_{x ∈ D(0,R)} min_i |x − c_i|，

则 D(0,R) 被覆盖 ⟺ ρ(c,R) ≤ 1，且 R_max(c) = sup{R : ρ(c,R) ≤ 1}，R_n = max_c R_max(c)。
ρ 对 R 单调不减，所以 R_max(c) 可二分得到。

## 已知值（2026-10-01 取自 Friedman 页面）

见 `data/records.json`。要点：

- 精确闭式：R_1=R_2=1，R_3=2/√3，R_4=√2，R_7=2，R_9=1+√2，R_19=√13（记录），R_25=√6+√3（记录）。
- 已证最优：n ≤ 10。
- n=11..25 仅为记录（未证最优），是突破的主要目标。

## 研究方向（候选）

1. 数值：改进 n=11..25 的记录，或把 n>25 扩展出来。
2. 精确：把数值记录识别为代数数闭式（RootApproximant + 紧约束方程组精确求解）。
3. 刚性/局部最优：紧约束图（tight points ↔ 圆）分析，KKT / 一阶最优性证书。
4. 下界/最优性：面积与边界弧长下界、组合分支定界 + 区间算术（参考 Fejes Tóth 对 n=8,9,10 的方法）。

## 记号约定

- 单位圆盘半径固定为 1，目标圆盘 D(0,R)，**目标中心总在原点**。
- 构型记作 c ∈ ℝ^{2n}，存储为十进制字符串（保留精度）。
- “紧点” (tight point)：候选点 x 使 min_i |x−c_i| = 1；它们是活跃约束。
